# Критика правила публикации панели (2026-09-01)

Источник: три разбора `generalPurpose` в сессии apply (транскрипт родителя `f9879df5-375e-46b8-ae7d-5094182a8552`). Полный текст — в субагентах; здесь сохранены выводы, по которым правились навык, шаблон и дельта.

## 1. Когда открывать (агент `25a2e56e-fd46-41f2-9803-9c83b9825c47`)

Панель открывалась, потому что просьба и «есть части» считались достаточными для записи файла. Отсечки «картина делает работу, которой нет в линейном чтении» не было.

Правило: писать файл, только если линейное чтение ещё путает отношение **или** рядом жива чужая картина. Просьба не задаёт вопрос «точно схему?» и не обязана создавать файл. Если файла нет — одна утвердительная строка.

Нужные случаи: одни части и движется фокус; две картины одного предмета; одно имя в двух случаях.

Риск ложного отказа: автор абзаца считает его ясным; «одни части, движется фокус» откажут как дубль списка шагов.

## 2. Язык картинки и шаблон (агент `19e67a23-71ce-4e77-b235-479bdc9991a6`)

Жёсткая схема возвращалась из хвоста `Main()`: пустое `form` рисовало ряд стопок по `items[]` (тот же класс ошибки, что «всё неизвестное → поток»).

Протокол: отношение, не счёт → нужна ли картина → смешанный источник → рецепт как подсказка → рецепт / чистый лист / текст.

Копия без выбранного языка не должна рисовать ни скелет, ни стопки. `ClassificationView` как `items.map` → колонка на пункт — литерал «N пунктов → N колонок».

## 3. Ревью первого экзамена «нельзя удержать в тексте» (агент `59c7a7aa-810c-4348-b8b4-25d52d1f4882`)

Первая правка навыка была дырявой:

- экзамен читался как «всё уже названо — файла нет» и ломал прямую просьбу после нормального абзаца про слои или классы;
- `Main` при опущенной form возвращал `null`, а `ClassificationView` из `Main` не вызывался — ленивый путь снова поток, таблица или шапка без языка;
- «если в сессии уже есть сопоставление классов» запрещало скелет на весь тред;
- два входа: верх навыка публиковал дубль «потому что просили», экзамен не открывал нужную панель.

Точечные замены (восприятие тех же частей / текущий вопрос / ясный абзац не отменяет скелет / пустой `Main` не публикация / голая просьба в сценарии классов) внесены в навык, шаблон, дельту и контракт поведения.
