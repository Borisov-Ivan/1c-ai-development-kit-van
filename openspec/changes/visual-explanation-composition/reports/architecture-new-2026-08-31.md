Kit-only. Нет `src/`, нет `.bsl`, нет метаданных 1С. Context Gap из‑за отсутствия explorer по модулям 1С не применяется.

## KB references

## Task

Закрепить, когда панель рядом с чатом открывается или намекается после разбора механизма слоями, и как на полотне рассказывать: вопрос, вывод, скелет, одна сцена. Не возвращать карту сценария, граф с координатами и словарь ролей штампа. Точка правки — существующий навык и шаблон, не новый продукт.

## Complexity

**Medium** (навык + шаблон + указатель исследования + дельта требований + уточнение двух инвариантов несущего решения). Один срез, нет перехватов 1С, apply — mechanical markdown и шаблон панели.

## Chosen Approach

**Approach**: Minimal changes — расширить существующий навык визуального объяснения.

**Rationale**: Why закрыт одним контрактом: авто и намёк по путанице частей, слоёв или случаев; на полотне скелет + одна сцена; таблица не страховка. Носитель, регистрация родителем, запрет графа, запрет отдельной команды, подавление авто на проверке постановки и ревью — без изменений (ADR-0010 остаётся несущим, не заменяется).

**Вердикт по черновику `design.md`: принять с дельтой (не переписывать с нуля).** Дельта внесена оркестратором в тот же ход.

## Simplicity Check

- **Viable alternatives**:
  1. **A (выбран)** — критерий путаницы в навыке и слоте «Дальше»; шаблон учит скелет + одну сцену; таблица только если вопрос — сравнение одних и тех же свойств.
  2. **B** — добавить в закрытый список четвёртый жанр «слои». Следующий механизм снова мимо списка.
  3. **C** — поменять только шаблон, список авто оставить. Молчание после разбора слоями останется.
  4. **D** — вернуть граф и координаты. Откат архива и запрета координатной раскладки.
  5. **E** — всегда открывать панель после любого многоабзацного ответа. Ломает «простой факт — текст».
  6. **F** — новый навык / новая команда. Параллельный продукт; Non-Goals.
  7. **G** — сменить только авто-критерий, лестницу «>6 частей → таблица» оставить. Сетка на просьбе «покажи схему» останется.
- **Selected simplest viable design**: **A**.
- **Why not simpler**: C не закрывает молчание. B не масштабируется. G не закрывает сетку. E/F нарушают сохранённые контракты архива. Вырезать ветки таблицы из шаблона не требуется для Why.
- **Complexity budget**: 5 рабочих файлов kit; 0 перехватов 1С; 0 новых команд; ветка таблицы сохраняется для вопроса-сравнения.

## Verdict on draft design.md

**Принять с правками.** Черновик не переписывать.

Обязательная дельта (внесена в `design.md`):

1. Модель данных **расширяется** шагами истории, не «оставляем без изменений».
2. Goals / Behavior Contract согласованы с приёмкой: без чата назвать вывод **и** почему одного наивного шага мало.
3. Зафиксирован точный текст двух уточняемых инвариантов ADR-0010 (D5).
4. Число частей не переводит в таблицу; при реальной нечитаемости — фокус / карточка вывода / полный текст.
5. «Источник → обработка → исход» — иллюстрация слоёв, не закрытый словарь скелета.

## Existing Mechanisms

Preference: расширить существующий навык, не создавать параллельный продукт.

| Механизм | Действие |
|----------|----------|
| навык визуального объяснения | Точка правки: авто/намёк, правила рассказа, запрет метатекста и HTML-плаката |
| шаблон панели | Точка правки: скелет + сцены; таблица не пример по умолчанию |
| примитивы среды панели | Обязательны; самодельный каркас страницы — нет |
| слот «Дальше» исследования | Тот же критерий, что авто в навыке |
| регистрация файла родителем | Без изменений |
| ADR-0010 Load-Bearing | Уточнить два инварианта, не заводить новый ADR |

Identity Filter: Chosen **снимает** закрытый список жанров, а не вводит allow-list форм 1С.

## Design Rationale

Навык должен кодировать, что делает объяснение читаемым, а не только чего избегать. Авто по путанице, не по жанру. Главная область — скелет слоями + одна сцена + карточка выбранного. Новое несущее решение не заводится: та же панель, другие правила рассказа.

## Blast Radius assessment

Секция в `design.md` закрывает прецедент для двух уточняемых контрактов. Классификация относительно архива `2026-08-31-universal-visual-explanation`:

| Архивный контракт | Вердикт |
|-------------------|---------|
| Прямая просьба без порога и журнала | extends |
| Авто только три жанра | revokes (замена критерием путаницы) |
| >6 частей → сразу таблица | revokes (сток в таблицу снимается) |
| «Правило о условиях → всегда таблица» | revokes как единственный вид |
| Запрет графа; родитель пишет файл; нет отдельной команды; авто нет на verify/review; нет словаря штампа | extends |

Supersedes Load-Bearing нет.

## ADR-0010 amendment (in-place, не Supersedes)

Статус Load-Bearing сохранить. Заменить только две строки `Protects-invariants`:

**Было:** автопанель только при развилке / сравнении / иерархии; нечитаемость упрощается таблицей или карточкой.

**Стало:**

- Авто и намёк — когда без картинки легко перепутать части, слои или случаи; три прежних жанра — иллюстрации, не закрытый список; простой факт и список без связей остаются текстом; вопрос «показать схему?» не спрашивается
- Форма следует за содержанием; много частей — раскрытие и фокус на скелете, не сброс в таблицу из‑за числа частей; таблица только если вопрос — сравнение одних и тех же свойств; нечитаемость не отказ; координатная раскладка не используется

Секцию Blast Radius внутри ADR-0010 (про 0008/0009) не переписывать. Индекс ADR: правка 0010, не строка «заменено».
