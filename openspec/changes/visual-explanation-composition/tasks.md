# Срез S1: Читаемое объяснение механизма слоями

**Сценарий:** После ответа про механизм из нескольких слоёв панель предлагается или открывается по просьбе; на полотне вопрос, вывод, скелет и одна сцена
**Primary acceptance:** Given: в чате есть обычный ответ про механизм из нескольких слоёв (не проверка постановки, не ревью, не пошаговый разбор, не обзор проекта). When: попросить «покажи схему» либо дочитать ответ, где без картинки путаются слои. Then: рядом с чатом панель кнопкой среды — видны вопрос, вывод, скелет и текущий шаг истории; это не сетка «элемент / пояснение / связь» как сток и не каталог всех шагов процесса; в чате нет пути к файлу
**Приёмка:** Ручная проверка в Cursor: открыть панель рядом с чатом. Сверка шаблона и навыка по файлам kit
**Связь со spec:** Requirement «Panel appears when a picture makes the answer easier» — Scenario «Разбор механизма слоями — панель или намёк», Scenario «Ветвление в ответе», Scenario «Простой факт без панели», Scenario «Три буллета без связей», Scenario «Проверка постановки без автопанели», Scenario «Просьба на проверке постановки», Scenario «Отказ «без схемы» в сессии»; Requirement «Form follows the content» — Scenario «Правило о условиях — не всегда таблица»; Requirement «Unreadable panel is simplified, not refused» — Scenario «Сложная схема упрощается», Scenario «Много частей — скелет, не сетка», Scenario «Нет среды панели»; Requirement «Panel tells one scene on a stable skeleton» — Scenario «Одна сцена на скелете», Scenario «Почему одного наивного шага мало»; Requirement «Panel uses environment components only» — Scenario «Полотно без водяного текста», Scenario «Координатный граф не публикуется»; Requirement «Panel does not explain itself» — Scenario «Нет метатекста про панель»
**Зависимости:** нет
**Режим apply:** mechanical

# Срез S2: Полотно как спутник сопоставления

**Сценарий:** По просьбе отметить отличия уже сказанного сопоставления полотно показывает классы сразу, без конвейера и без пачки кнопок
**Primary acceptance:** Given: в чате уже есть сопоставление одноимённых эффектов (классы) и просьба дать схему, отдельно отметив отличия; журнала разбора может не быть. When: открыть панель по просьбе (без подсказки «три колонки»). Then: одно полотно класса сопоставление; уточнённый пункт — элемент класса, не ветка процесса; пометки одного ранга; интерактив не обязателен; если якорь доказательства есть — один или точечный, не пачка кнопок в один файл; в чате нет пути к файлу
**Приёмка:** Ручная проверка в Cursor. Слепой прогон без хардкода сюжета. Сверка навыка и шаблона по файлам kit
**Связь со spec:** Requirement «Graphic language matches the relation in the text» — Scenario «Сопоставление уже сказанных классов», Scenario «Смешанный источник не даёт конвейер»; Requirement «Panel tells one scene on a stable skeleton» — Scenario «Плакат всех случаев не публикуется»; Requirement «Form follows the content» — Scenario «Сравнение свойств — таблица допустима», Scenario «Таблица свойств без обязательных кнопок», Scenario «Неизвестный жанр не даёт отказ»
**Зависимости:** нет
**Режим apply:** mechanical

## 1. Навык, шаблон и опорное решение

- [ ] S2.1 Заменить в `.cursor/skills/visual-explanation/SKILL.md` шаги выбора и сборки носителя: сначала назвать одну работу над уже сказанным текстом, затем выбрать язык картинки под то же отношение, чтобы сопоставление не становилось конвейером, а скелет оставался рецептом разбора механизма (D2, D8, D9, RCA 2026-09-01; Scenario «Сопоставление уже сказанных классов», Scenario «Смешанный источник не даёт конвейер»).
