# Срез S1: Читаемое объяснение на панели

**Сценарий:** После ответа про механизм из нескольких слоёв панель предлагается или открывается по просьбе; на полотне вопрос, вывод, скелет и одна сцена, не таблица и не плакат
**Primary acceptance:** Given: в чате есть обычный ответ про механизм из нескольких слоёв (не проверка постановки, не ревью, не пошаговый разбор, не обзор проекта). When: попросить «покажи схему» либо дочитать ответ, где без картинки путаются слои. Then: рядом с чатом панель кнопкой среды — видны вопрос, вывод, скелет и текущий шаг истории; это не сетка «элемент / пояснение / связь» и не плакат всех случаев; в чате нет пути к файлу
**Приёмка:** Ручная проверка в Cursor: открыть панель рядом с чатом. Сверка шаблона и навыка по файлам kit
**Связь со spec:** Requirement «Panel appears when a picture makes the answer easier» — Scenario «Разбор механизма слоями — панель или намёк», Scenario «Ветвление в ответе», Scenario «Простой факт без панели», Scenario «Три буллета без связей», Scenario «Проверка постановки без автопанели», Scenario «Просьба на проверке постановки», Scenario «Отказ «без схемы» в сессии»; Requirement «Form follows the content» — Scenario «Правило о условиях — не всегда таблица», Scenario «Сравнение свойств — таблица допустима», Scenario «Неизвестный жанр не даёт отказ»; Requirement «Unreadable panel is simplified, not refused» — Scenario «Сложная схема упрощается», Scenario «Много частей — скелет, не сетка», Scenario «Нет среды панели»; Requirement «Panel tells one scene on a stable skeleton» — Scenario «Одна сцена на скелете», Scenario «Почему одного наивного шага мало», Scenario «Плакат всех случаев не публикуется»; Requirement «Panel uses environment components only» — Scenario «Полотно без водяного текста», Scenario «Координатный граф не публикуется»; Requirement «Panel does not explain itself» — Scenario «Нет метатекста про панель»
**Зависимости:** нет
**Режим apply:** mechanical

для таблицы и карточки вывода дробление на сцены не требуется); теснота подписей по данным сборки — сильнее фокус, карточка вывода или полный текст в чате, не отказ и не сетка «из‑за счёта»; рассказ скелета — вопрос, короткий вывод, скелет именованных частей, одна сцена за раз («Назад / Дальше»), части не в фокусе остаются на месте и тускнеют, не скрываются (таблица сравнения свойств и карточка вывода скелет не обязаны показывать);   - **Primary (обязательно):** Given: в чате есть обычный ответ про механизм из нескольких слоёв (не проверка постановки, не ревью, не пошаговый разбор, не обзор проекта). When: попросить «покажи схему» либо дочитать ответ, где без картинки путаются слои.   - Scenario «Координатный граф не публикуется» (опционально): узлы не разложены по координатам; это не граф со стрелками поверх абсолютной раскладки
