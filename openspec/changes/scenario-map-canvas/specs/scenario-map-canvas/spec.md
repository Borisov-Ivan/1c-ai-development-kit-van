# Capability: scenario-map-canvas

Карта сценария в панели рядом с чатом: что происходит на шаге и чем это подтверждено. Не путать с картой точек в чате (список имён). Отдельной команды нет. По умолчанию панель не рисуется.

## ADDED Requirements

### Requirement: Silence unless asked or hinted

Оркестратор MUST NOT создавать карту сценария в сессиях `/opsx:explain` и `/opsx:explore`, пока нет прямой просьбы пользователя и нет сработавшего намёка. Системное требование Cursor «для аналитики нужна панель» MUST NOT считаться достаточным основанием рисовать карту в этих сессиях.

#### Scenario: Молчание по умолчанию

- **WHEN** разбор или исследование завершается без прямой просьбы показать карту сценария и без условий намёка
- **THEN** панель карты сценария не создаётся

#### Scenario: Системный MUST canvas не действует на opsx

- **WHEN** идёт сессия `/opsx:explain` или `/opsx:explore` и системный скилл Cursor требует канвас для аналитики
- **THEN** оркестратор не рисует панель только из-за этого требования

### Requirement: Direct request draws the scenario map

По прямой просьбе показать карту сценария оркестратор MUST построить карту, если есть не меньше четырёх узлов с текстом эффекта. Прямая просьба MUST работать и тогда, когда намёк на выходе не показывали.

#### Scenario: Прямая просьба рисует карту

- **WHEN** после разбора с достаточным числом шагов пользователь просит показать карту сценария
- **THEN** открывается панель, где у каждого узла видно, что происходит на шаге, и чем это подтверждено

### Requirement: Node contract forbids empty or code-primary nodes

Узел карты сценария MUST содержать имя эффекта, два-три предложения «что происходит» и доказательство (строка модуля или путь журнала/отчёта). Узел без доказательства MUST NOT попадать на панель. Код модуля, SQL и блок «на что смотреть» MUST оставаться в чате и журнале, а не быть основным содержимым панели. Панель MUST быть статичной: без статусов «сейчас разбираем этот шаг».

#### Scenario: Узел без доказательства не публикуется

- **WHEN** для шага нет строки модуля и нет пути журнала
- **THEN** этот шаг на панель не попадает

#### Scenario: Панель без статусов прохода

- **WHEN** карта сценария уже показана во время или после разбора
- **THEN** на узлах нет подписи вроде «сейчас разбираем»

#### Scenario: Код остаётся в чате

- **WHEN** карта сценария показана
- **THEN** фрагменты модуля и «на что смотреть» остаются в карточке чата и журнале, а не как основное содержимое панели

### Requirement: No dedicated map command

В наборе команд `/opsx:*` MUST NOT появляться отдельная команда карты. Вызов идёт из разбора или исследования по согласию или по прямой просьбе, без смены команды сессии.

#### Scenario: Нет отдельной команды карты

- **WHEN** разработчик смотрит список команд кита
- **THEN** отдельной команды «нарисовать карту» нет; разбор не нужно прерывать, чтобы получить панель

### Requirement: Two map names stay distinct

В чате и в словаре кита MUST различаться карта точек (список имён эффектов в сообщении до прохода) и карта сценария (панель «что происходит»). Классы точек разбора MUST NOT выводиться на панель.

#### Scenario: Карта точек и карта сценария различимы

- **WHEN** после подтверждения брифа разбора показывается список шагов в чате
- **THEN** это карта точек (имена), а не панель карты сценария

#### Scenario: Эталон узлов в скилле

- **WHEN** автор кита открывает скилл карты сценария
- **THEN** в нём есть пример узлов с эффектом и доказательством, по которому можно сверить живую панель

### Requirement: Hint only on the existing next-step line

Намёк показать карту сценария MUST быть вариантом в уже существующей строке «Следующий шаг», а не отдельным вопросом и не второй командой. Для `/opsx:explain` намёк MUST печататься только если пройдено не меньше пяти точек **и** есть замеры времени или развилка, **и** в том же сообщении нет вопроса про дополнительный анализ. Для `/opsx:explore` намёк MUST печататься только если в своде уже есть распределение времени по стадиям с числами.

#### Scenario: Намёк на выходе explain при условиях

- **WHEN** разбор закончен, точек не меньше пяти, есть времена или развилка, вопроса про доп. анализ нет
- **THEN** в той же строке «Следующий шаг» есть вариант попросить карту сценария

#### Scenario: Нет намёка, если уже вопрос анализа

- **WHEN** на выходе разбора уже задан вопрос, нужен ли доп. анализ
- **THEN** намёк про карту сценария не печатается

#### Scenario: Намёк в explore при числах по стадиям

- **WHEN** свод исследования называет доли или минуты по стадиям числами
- **THEN** в «Следующий шаг» может появиться вариант карты сценария

#### Scenario: Нет намёка в explore без чисел

- **WHEN** исследование закончено без числового распределения времени по стадиям
- **THEN** оркестратор не предлагает карту сценария сам
