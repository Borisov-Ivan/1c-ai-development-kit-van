# Срез S1: Карта сценария по просьбе и намёк на выходе разбора

**Сценарий:** После разбора кода панель рядом с чатом молчит, пока её не попросили; по просьбе «покажи карту сценария» появляются узлы «что происходит на шаге» с доказательством, а на длинном разборе с замерами карту можно попросить прямо из строки «Следующий шаг».
**Primary acceptance:** Given разбор с достаточным числом шагов; When пользователь ничего не просил — панели нет; When пользователь говорит «покажи карту сценария» — приходят узлы с эффектом шага и доказательством (панель или те же узлы в журнале разбора).
**Приёмка:** сессия разбора (реальная или смоделированная) + сверка текста скилла и шаблонов; без ИБ продукта.
**Связь со spec:** Requirement «Silence unless asked or hinted» — Scenario «Молчание по умолчанию», «Системный MUST canvas не действует на opsx»; Requirement «Direct request draws the scenario map» — Scenario «Прямая просьба рисует карту», «Карта во время прохода из уже пройденных точек», «Просьба при числе узлов ниже порога», «Панель недоступна — узлы в журнале»; Requirement «Node contract forbids empty or code-primary nodes» — Scenario «Узел без доказательства не публикуется», «Панель без статусов прохода», «Код остаётся в чате»; Requirement «No dedicated map command» — Scenario «Нет отдельной команды карты»; Requirement «Two map names stay distinct» — Scenario «Карта точек и карта сценария различимы», «Эталон узлов в скилле»; Requirement «Hint only on the existing next-step line of explain» — Scenario «Намёк на выходе explain при условиях», «Нет намёка, если уже вопрос анализа», «Исследование по-прежнему предлагает разбор».
**Зависимости:** нет
**Режим apply:** mechanical

## 5. Приёмка

- [ ] S1.accept Принять срез S1 «Карта сценария по просьбе и намёк на выходе разбора» — карта приходит по просьбе, молчит без неё и не подменяет карту точек:
  - **Primary (обязательно):** провести разбор (реальный или смоделированный) с достаточным числом шагов → без просьбы панель не появляется → сказать «покажи карту сценария» → прийти должны узлы с эффектом шага и доказательством (панель либо те же узлы в журнале разбора)
  - Scenario «Карта во время прохода из уже пройденных точек» (опционально): попросить карту до записи журнала — на ней только уже разобранные шаги
  - Scenario «Просьба при числе узлов ниже порога» (опционально): попросить карту после двух-трёх шагов — панели нет, в чате одна строка, почему и что даст карту
  - Scenario «Панель недоступна — узлы в журнале» (опционально): при недоступной панели те же узлы видны в журнале разбора, в чате одна строка об этом
  - Scenario «Узел без доказательства не публикуется» (опционально): шаг без строки модуля и без пути журнала на карте отсутствует
  - Scenario «Панель без статусов прохода» (опционально): на узлах нет подписей вроде «сейчас разбираем»
  - Scenario «Код остаётся в чате» (опционально): фрагменты модуля и «на что смотреть» остаются в карточке чата и журнале, а не на панели
  - Scenario «Намёк на выходе explain при условиях» (опционально): на выходе разбора с ≥5 точками и замерами, где кандидатов анализа нет, в строке «Следующий шаг» есть вариант попросить карту
  - Scenario «Нет намёка, если уже вопрос анализа» (опционально): на выходе с вопросом про доп. анализ намёка про карту нет
  - Scenario «Карта точек и карта сценария различимы» (опционально): список шагов после подтверждения брифа читается как карта точек, а не как панель
