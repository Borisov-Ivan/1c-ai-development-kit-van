# Срез S1: Наблюдаемый результат

**Сценарий:** пользователь выполняет действие и видит результат на форме.
**Primary acceptance:** выполнить действие → результат виден.
**Приёмка:** ручной тест.
**Связь со spec:** Requirement «Видимый результат действия» — Scenario «Результат виден после действия»; Requirement «Восстановление после ошибки» — Scenario «Состояние восстановлено после ошибки».
**Зависимости:** нет.

- [ ] S1.1 Описать в `design.md` наблюдаемый результат действия (ось `visible-result`).
- [ ] S1.2 Описать в `design.md` восстановление после ошибки (ось `error-recovery`).
- [ ] S1.accept Принять срез S1 «Наблюдаемый результат» — результат действия виден:
  - **Primary (обязательно):** выполнить действие → результат виден на форме
  - Scenario «Состояние восстановлено после ошибки» (опционально): действие с ошибкой → форма в исходном состоянии
