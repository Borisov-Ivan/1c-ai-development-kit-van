# Срез S1: Читаемая карта со смыслом

**Сценарий:** разработчик просит карту сценария по теме, где по ней передано несколько отчётов, и открывает панель штатной кнопкой среды.
**Primary acceptance:** попросить карту сценария по теме с несколькими отчётами → открыть панель штатной кнопкой среды → без единого клика видны направление каждой связи, легенда использованных типов, полосы с именами слоёв своих узлов, уже выбранный узел-виновник с эффектом в панели деталей и ловушка — почему ожидаемое событие сброса не наступает.
**Приёмка:** ручной осмотр живой панели после пересборки карты; статическая часть — сверка текста скилла, шаблона панели, роли сборщика и эталонов задачами среза.
**Связь со spec:** Requirement «Direct request draws the scenario map» — Scenario «С узла открывается доказательство, новый чат с панели не запускается»; Requirement «Technical fallback is not a map» — Scenario «Провал смысла не уходит в текстовый резерв»; Requirement «Node contract forbids empty or code-primary nodes» — Scenario «Связь без видимого отношения не выдумывается», Scenario «Аннотации не добирают порог»; Requirement «Causal map has layers or branches» — Scenario «Слои или ветвление видны на панели», Scenario «Направление связей и легенда видны без клика», Scenario «Главный вывод виден без клика по узлу», Scenario «Вывод только в шапке не публикуется», Scenario «Находка, меняющая действие, на полотне», Scenario «Ловушка одной подписи видна на полотне», Scenario «Плашка без доказательства не публикуется», Scenario «Режим не прячет рёбра»; Requirement «Two map names stay distinct» — Scenario «Эталон карты в скилле — граф, не список».
**Зависимости:** нет.
**Режим apply:** mechanical

- [ ] S1.accept Принять срез S1 «Читаемая карта со смыслом» — карта читается с первого взгляда и не теряет дорогое знание:
  - **Primary (обязательно):** попросить карту сценария по теме с несколькими отчётами → открыть панель штатной кнопкой среды → без единого клика видны направление каждой связи, легенда, полосы с именами слоёв своих узлов, уже выбранный узел-виновник с эффектом в панели деталей и ловушка — почему ожидаемое событие сброса не наступает (Scenario «Направление связей и легенда видны без клика», Scenario «Главный вывод виден без клика по узлу», Scenario «Находка, меняющая действие, на полотне», Scenario «Ловушка одной подписи видна на полотне»)
  - Scenario «Слои или ветвление видны на панели» (опционально): на карте с разными слоями взглядом отличаются уровни или ветки; если полоса подписана, подпись совпадает со слоем её узлов, а не с рангом раскладки
  - Scenario «С узла открывается доказательство, новый чат с панели не запускается» (опционально): выбрать узел с крупным модулем — файл не открылся; после нажатия кнопки доказательства открылся нужный диапазон; нового чата с панели нет
  - Scenario «Вывод только в шапке не публикуется» (опционально): на наборе, где ответ есть только в тексте шапки, панель не появилась, в чате одна строка, чего не хватает
  - Scenario «Плашка без доказательства не публикуется» (опционально): на наборе с аннотацией без доказательства или без якоря панель не появилась, в чате одна строка, чего не хватает
  - Scenario «Аннотации не добирают порог» (опционально): при трёх связанных узлах и двух аннотациях панель не появилась
  - Scenario «Режим не прячет рёбра» (опционально): переключить режим — набор узлов и связей тот же, изменилась подсветка, стены одинаковых карточек нет; аннотаций не больше двух
  - Scenario «Связь без видимого отношения не выдумывается» (опционально): при расхождениях отчётов без видимого отношения ребро не появилось, отсутствие зафиксировано аннотацией или панель не опубликована за счёт выдуманных стрелок, в чате одна строка, чего не хватает
