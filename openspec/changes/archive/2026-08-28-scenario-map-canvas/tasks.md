# Срез S2: Карта показывает причинность

**Сценарий:** Разработчик впервые просит «покажи карту сценария» и получает схему со подписанными связями, а не список пунктов; текстовый резерв не выдаётся за карту.
**Primary acceptance:** Given панели в проекте ещё не было и файл не назван; When «покажи карту сценария» при не меньше четырёх публикуемых сущностях; Then рядом с чатом схема открывается штатной кнопкой среды со подписанными связями (уровни или ветки — если есть, иначе цепочка), файл вне git.
**Приёмка:** сессия (реальная или смоделированная) + сверка скилла и эталонов; без ИБ продукта.
**Связь со spec:** Requirement «Direct request draws the scenario map» — Scenario «Прямая просьба рисует карту», «Первая просьба в проекте без открытой панели», «Панель открывается штатной кнопкой среды», «С узла открывается доказательство, новый чат с панели не запускается», «Порядок прохода не выдаётся за причинность», «Прямая просьба после выхода разбора», «Просьба при числе сущностей ниже порога», «Просьба при линейной цепочке»; Requirement «Causal map has layers or branches» — Scenario «Слои или ветвление видны на панели»; Requirement «Node contract forbids empty or code-primary nodes» — Scenario «Список без связей не публикуется как карта», «Связь без видимого отношения не выдумывается»; Requirement «Technical fallback is not a map» — Scenario «Среда без панели — резерв в журнале», «Запись журнала сохраняет резерв»; Requirement «Map outside walkthrough uses named source» — Scenario «Вне разбора без источника — отказ», «Просьба в исследовании берёт текущий отчёт»; Requirement «Two map names stay distinct» — Scenario «Эталон карты в скилле — граф, не список».

  - Scenario «Среда без панели — резерв в журнале» (опционально): при недоступной панели в чате сказано, что интерактивной схемы нет
  - Scenario «Карта во время прохода из уже пройденных точек» (опционально): попросить карту до записи журнала — на ней только уже разобранные шаги

# Срез S3: Команды предлагают схему по топологии

**Сценарий:** Исследование и разбор сами предлагают схему, когда связи важнее списка; на линейных шагах молчат; правило не зависит от темы механизма.
**Primary acceptance:** Given отчёт с четырьмя связанными сущностями и топологическим признаком, без замеров времени; When формируется «Дальше» исследования или выход разбора; Then одно конкретное предложение схемы.
**Приёмка:** смоделированные отчёты + сверка шаблонов; без ИБ продукта.
**Связь со spec:** Requirement «Offer by topology not by topic» — Scenario «Исследование предлагает схему при топологии без замеров», «Разбор предлагает схему на подтверждении списка без порога публикации», «Разбор предлагает схему на выходе без замеров времени», «На линейных двух шагах схему не предлагают», «Предложение не зависит от темы механизма»; Requirement «Hint only on an existing decision line» — Scenario «Намёк на выходе разбора при топологии», «Нет намёка, если уже вопрос анализа», «Исследование не предлагает карту и разбор сразу», «Нет предложения в финале исследования с постановкой»; Requirement «Causal map has layers or branches» — Scenario «Семь линейных шагов не обязаны давать карту»; Requirement «Direct request draws the scenario map» — Scenario «Согласие на предложение рисует карту», «Согласие до первой карточки разбора запоминает фокус», «Отложенное согласие публикует карту без повторного вопроса», «Согласие было, порог до выхода не набрался», «Согласие при неподтвердившейся топологии даёт цепочку».
**Зависимости:** S2
**Режим apply:** mechanical
