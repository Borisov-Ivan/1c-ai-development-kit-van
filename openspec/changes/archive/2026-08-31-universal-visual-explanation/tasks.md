# Срез S1: Визуальное объяснение вместо карты сценария

**Сценарий:** Разработчик просит показать, как устроен ответ — рядом с чатом открывается понятная панель; старый конвейер карты больше не вызывается
**Primary acceptance:** Given: в чате есть обычный ответ на вопрос (не `/opsx:verify`, не `/review`). When: попросить «покажи, как это устроено». Then: рядом с чатом открывается панель кнопкой среды — видны вопрос, вывод и структура ответа; в чате нет пути к файлу панели; это визуальное объяснение, не граф старой карты сценария (нет отказа «мало сущностей» / «укажите отчёт»)
**Приёмка:** Ручная проверка в Cursor: открыть панель рядом с чатом. Старый скилл — сверка по файлам kit
**Связь со spec:** Requirement «Direct request opens a visual explanation» — Scenario «Просьба на обычный ответ в чате», Scenario «Просьба без порога по числу элементов», Scenario «Просьба в середине разбора», Scenario «Среда есть — не подменять панелью рисунок в чате»; Requirement «Panel appears when a picture makes the answer easier» — Scenario «Ветвление в ответе», Scenario «Простой факт без панели», Scenario «Три буллета без связей», Scenario «Проверка постановки без автопанели», Scenario «Просьба на проверке постановки», Scenario «Отказ «без схемы» в сессии»; Requirement «Panel explains the same question as the chat» — Scenario «Вывод виден без каталога сущностей», Scenario «Вывод только в шапке не публикуется», Scenario «Догадка не выдаётся за факт»; Requirement «Form follows the content» — Scenario «Правило о условиях — таблица или сравнение», Scenario «Неизвестный жанр не даёт отказ»; Requirement «Unreadable panel is simplified, not refused» — Scenario «Сложная схема упрощается», Scenario «Нет среды панели»; Requirement «Panel opens with the environment button» — Scenario «Первая схема в проекте», Scenario «Выбор не открывает файл сам»; Requirement «Platform schema object is not a kit panel» — Scenario «Голая «покажи схему»», Scenario «Схема компоновки», Scenario «Оба чтения «покажи схему»»; Requirement «No dedicated visualization command» — Scenario «Просьба внутри исследования»; Requirement «Map cue in dispatcher is a pointer» — Scenario «Cue «покажи схему»»
**Зависимости:** нет
**Режим apply:** mechanical

## 6. Приёмка

- [x] S1.accept Принять срез S1 «Визуальное объяснение вместо карты сценария» — рядом с чатом открывается визуальное объяснение текущего ответа; старый конвейер карты снят:
  - **Primary (обязательно):** Given: в чате есть обычный ответ на вопрос (не `/opsx:verify`, не `/review`). When: попросить «покажи, как это устроено». Then: рядом с чатом открывается панель кнопкой среды — видны вопрос, вывод и структура ответа; в чате нет пути к файлу панели; это визуальное объяснение, не граф старой карты сценария (нет отказа «мало сущностей» / «укажите отчёт»)
  - Scenario «Просьба без порога по числу элементов» (опционально): схема на ответ с менее чем четырьмя сущностями — панель есть, отказа «мало сущностей» нет
  - Scenario «Просьба в середине разбора» (опционально): просьба до записи журнала — панель из уже сказанного, команда разбора не меняется
  - Scenario «Голая «покажи схему»» (опционально): предмет не схема 1С — открывается панель объяснения
  - Scenario «Просьба внутри исследования» (опционально): панель есть, исследование продолжается
  - Scenario «Ветвление в ответе» (опционально): развилка «если / иначе» — панель открывается без отдельной просьбы
  - Scenario «Простой факт без панели» (опционально): одно имя поля — панели нет
  - Scenario «Три буллета без связей» (опционально): три пункта без ветки — панели нет
  - Scenario «Отказ «без схемы» в сессии» (опционально): после «без схемы» автопанель и намёк не повторяются
  - Scenario «Проверка постановки без автопанели» (опционально): на `/opsx:verify` или `/review` без отдельной просьбы панели нет
  - Scenario «Просьба на проверке постановки» (опционально): на `/opsx:verify` или `/review` попросить «покажи, как устроено» — панель кнопкой среды, в чате одна строка
  - Scenario «Оба чтения «покажи схему»» (опционально): фраза двусмысленна — одна строка выбора, панели нет до ответа
  - Scenario «Правило о условиях — таблица или сравнение» (опционально): «когда срабатывает / когда нет» — колонки или сравнение, не обязательная цепочка
  - Scenario «Сложная схема упрощается» (опционально): нечитаемое полотно не объявляется готовым; публикуется более простая форма
  - Scenario «Схема компоновки» (опционально): «покажи схему компоновки» — ответ про 1С, панели kit нет
  - Scenario «Выбор не открывает файл сам» (опционально): выбор элемента не открывает файл и не стартует новый чат
  - Scenario «Догадка не выдаётся за факт» (опционально): недоказанная связь подписана как догадка или отсутствует
