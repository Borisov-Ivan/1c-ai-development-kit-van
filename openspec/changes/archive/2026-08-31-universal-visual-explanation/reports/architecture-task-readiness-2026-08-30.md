## Замечания без возврата

1. **Токены `presentation.form`.** В D3 набор задан по-русски (поток, сравнение/таблица, иерархия, карточка вывода), машинные литералы не перечислены. Исполнитель S1.1 и S1.2 в одном apply фиксирует одну таблицу строк в скилле и в константах шаблона. Новую задачу не заводить.

2. **`computeDAGLayout` «при необходимости».** Не две поставки продукта: штатный примитив среды, когда есть `relations[]` и форма поток/иерархия. Самописный поиск места для подписи и `NODE_W = 180` уже запрещены S1.2 и ловятся S1.11. Критерий «когда» не требует уточнения у заказчика.

3. **Migration Plan vs S1.7.** Абзац миграции в design не называет `AGENTS.md` и `.cursor/docs/agents-CHANGELOG.md`. Задача S1.7 их содержит; apply идёт по `tasks.md`. Править design до старта не обязательно.

4. **Неоднозначность «панель / объект 1С».** Spec «если оба чтения ещё живы — одна строка выбора» полнее, чем краткая строка S1.1. Исполнитель читает spec вместе с задачей. Отдельного возврата нет.

5. **Разбор постановки (вне этой оценки).** Замечания про запрет панели на verify/review по просьбе и про операционализацию лестницы относятся к независимому разбору постановки; Chosen A и список задач as-is исполняемы.
