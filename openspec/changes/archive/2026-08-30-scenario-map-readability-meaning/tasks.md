# Срез S1: Читаемая карта со смыслом

**Сценарий:** разработчик просит карту сценария по теме, где по ней передано несколько отчётов, и открывает панель штатной кнопкой среды.
**Primary acceptance:** попросить карту сценария по теме с несколькими отчётами → открыть панель штатной кнопкой среды → скрыть шапку → назвать ответ на вопрос шапки и ловушку; имена сущностей читаются без сжатия всего полотна; стартово выбран носитель исхода или виновника.
**Приёмка:** ручной осмотр живой панели после пересборки карты; статическая часть — сверка текста скилла, шаблона панели, роли сборщика и эталонов задачами среза.
**Связь со spec:** Requirement «Direct request draws the scenario map» — Scenario «С узла открывается доказательство, новый чат с панели не запускается»; Requirement «Technical fallback is not a map» — Scenario «Провал смысла не уходит в текстовый резерв»; Requirement «Node contract forbids empty or code-primary nodes» — Scenario «Связь без видимого отношения не выдумывается», Scenario «Строка таблицы не выдумывает правило», Scenario «Аннотации не добирают порог»; Requirement «Causal map has layers or branches» — Scenario «Слои или ветвление видны на панели», Scenario «Направление связей и легенда видны без клика», Scenario «Главный вывод виден без клика по узлу», Scenario «Вывод только в шапке не публикуется», Scenario «Находка, меняющая действие, на полотне», Scenario «Ловушка одной подписи видна на полотне», Scenario «Плашка без доказательства не публикуется», Scenario «Переключатель вида не прячет рёбра», Scenario «Ответ читается при скрытой шапке», Scenario «Текст полотна читается в ширине панели», Scenario «Стартово выбран носитель исхода», Scenario «Таблица со смысловыми колонками отвечает на вопрос»; Requirement «Two map names stay distinct» — Scenario «Эталоны показывают средство, отвечающее на вопрос».
**Зависимости:** нет.
**Режим apply:** mechanical

  - Scenario «Аннотации не добирают порог» (опционально): при трёх связанных сущностях и двух аннотациях панель не появилась
  - Scenario «Переключатель вида не прячет рёбра» (опционально, если средство — граф): переключить вид — набор узлов и связей тот же, изменилась раскладка, стены одинаковых карточек нет; аннотаций не больше двух
  - Scenario «Связь без видимого отношения не выдумывается» (опционально): при расхождениях отчётов без видимого отношения ребро не появилось, отсутствие зафиксировано аннотацией или панель не опубликована за счёт выдуманных стрелок, в чате одна строка, чего не хватает
  - Scenario «Строка таблицы не выдумывает правило» (опционально): на содержании «правило о условиях» строка без видимого в источнике основания не публикуется, в чате одна строка, чего не хватает
  - Scenario «Провал смысла не уходит в текстовый резерв» (опционально / сверка скилла): при провале смысла панель не появилась, текстовый резерв по этой причине не пишется
  - Scenario «Эталоны показывают средство, отвечающее на вопрос» (опционально / сверка): в скилле есть эталон ответа, эталон списка без связей и эталон «полотно без смысла»
  - Scenario «Таблица со смысловыми колонками отвечает на вопрос» (опционально): на содержании «правило о условиях» таблица при скрытой шапке даёт ответ; стены карточек нет
