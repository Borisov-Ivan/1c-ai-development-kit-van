# Spec sync — scenario-map-readability-meaning — 2026-08-30

Capability: `scenario-map-canvas` (MODIFIED).

- Direct request: порог и отсев по средству (граф / таблица); клик выбирает узел или строку.
- Technical fallback: провал смысла не уходит в текстовый резерв.
- Node contract: таблица без обязательной инцидентной связи; запрет выдуманных строк.
- Causal map: ответ при скрытой шапке; два средства; бюджет ширины; аннотации; стартовый узел.
- Two map names: эталоны графа, таблицы и отказа по смыслу.

Сохранено из более ранней дельты `overview-map-offer`: сессия описания как источник и слот намёка (эта дельта их не отменяла).
