## Verified facts

- Симптом: после просьбы нарисовать карту проверки постановки кнопки среды рядом с чатом нет.
- Доказательство 1: первая запись живого файла панели шла скриптом оболочки; проверка типов носителя в результате записи не вернулась.
- Доказательство 2: та же запись инструментом записи файла вернула шесть ошибок типов (`key` на `Button`/`Row`/`Text`; якорь аннотации в колбэке без сужения).
- Доказательство 3: после сужения якоря и переноса `key` на нативные обёртки проверка типов той же записи — без ошибок.

## Root Cause

1. Почему нет кнопки? Среда не зарегистрировала панель.
2. Почему не зарегистрировала? Файл появился дампом оболочки, без проверки типов носителя; шаблон при прямой записи нечистый по типам.
3. Почему шаблон нечистый? `Button`/`Row`/`Text` носителя не принимают `key`; сужение союза якоря теряется внутри колбэка `find`.
Корневая причина: регистрация не тем способом, которым среда индексирует панель, плюс шаблон, который не проходит проверку типов носителя.
Фикс: прямая запись файла + шаблон без `key` на компонентах носителя и с локальным сужением якоря.

## Architectural Impact

- Вызывающие: родительский агент сессии при регистрации карты.
- Контракты: успех штатной кнопкой среды не ослаблен; аварийная строка с путём по-прежнему только восстановление.
- Масштаб: точечный (шаблон панели + шаг регистрации скилла). Сценарий приёмки не меняется.
- Architect Gate: не требовался — типы шаблона уже согласованной панели, не новый UX-сценарий.
