## ADDED Requirements

### Requirement: Quality controller template path is resolvable

Скилл постановки ЗНИ SHALL ссылаться на существующий шаблон контролёра срезов `.cursor/skills/1c-agent-patterns/quality-controller.md`. Относительное имя `openspec-quality-controller.md` без каталога MUST NOT оставаться рабочей ссылкой.

#### Scenario: Ссылка контролёра открывается

- **WHEN** оркестратор на постановке ЗНИ делегирует проверку срезов по скиллу постановки
- **THEN** путь шаблона указывает на файл `1c-agent-patterns/quality-controller.md` и файл существует

### Requirement: Search fallback without semantic tool

Если смысловой поиск по репозиторию в среде недоступен, оркестратор и агенты SHALL искать через Grep и Glob. Отсутствие смыслового поиска MUST NOT считаться стопом протокола.

#### Scenario: Fallback поиска

- **WHEN** в среде нет инструмента смыслового поиска, а нужно найти символ или путь
- **THEN** поиск идёт через Grep и Glob; сессия не останавливается из‑за отсутствия смыслового поиска

### Requirement: Generic explore has no fast mode

В плане анализа файлов вызов generic explore SHALL быть обычным вызовом роли `explore`. Режим `explore/fast` MUST NOT указываться: такого режима в вызове нет.

#### Scenario: План анализа без режима fast

- **WHEN** стратегия анализа поручает субагенту разбор файла данных вне 1С
- **THEN** в плане указан обычный explore, без суффикса `fast`

### Requirement: Map designer does not full-read the canvas skill

Агент-картограф MUST NOT читать скилл карты целиком перед ответом. Контракт средства и порога SHALL приходить в бриф от оркестратора или из короткого фрагмента, достаточного для манифеста.

#### Scenario: Картограф без полного чтения скилла карты

- **WHEN** оркестратор вызывает сборщика манифеста карты
- **THEN** агент не читает скилл карты целиком; в брифе уже есть средство, порог и запрет выдуманных рёбер

### Requirement: Style guide is read by cited section

Оркестратор MUST NOT читать стайл-гайд оформления чата целиком на каждое сообщение. Если скилл ссылается на конкретный раздел, оркестратор SHALL читать только этот раздел.

#### Scenario: Стайл-гайд по цитате

- **WHEN** скилл реализации ссылается на раздел карточки завершения
- **THEN** оркестратор читает этот раздел, а не весь файл стайл-гайда
