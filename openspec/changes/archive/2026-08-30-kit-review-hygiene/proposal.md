## Why

В поставке kit в чужой проект утекают имена реальных конфигураций: фильтр охвата маркеров зашит путями чужой выгрузки, а учебные эталоны и команды повторяют те же имена. В другом проекте развилка после последнего среза молча пропускает предрелиз, а в копируемых файлах остаются чужие проекты. Порог предложения схемы после описания ЗНИ ещё считает «оба отсева», хотя главное средство карты уже может быть таблицей. На каждом ходе сессии повторно читается весь скилл, хотя протокол уже в контексте.

## What Changes

1. Признак охвата маркеров считается по сегментам пути `cf` / `cfe` (из карточки проекта, если она есть, иначе из самих путей в задачах). Ярлык «конфигурация как ЭДО и ЭА» уходит: словарь один — `cf` / `cfe` / `mixed` / не определён. Развилка после последнего среза не меняет смысл: код расширения — три слова; kit-only и только база — архив без предрелиза.
2. После описания ЗНИ порог предложения схемы совпадает с правилами выбранного средства карты. Согласие по-прежнему отдаёт в сборщика тот же один отчёт; фраза про соседнюю ЗНИ уходит.
3. Полный скилл команды читается только на входе сессии. На следующих ходах действует тот же протокол, без повторного Read. Имена служебных карточек при обрезке скилла живут в правиле сессии. Строка диспетчера про карту — короткий указатель, без копипасты протокола.
4. Сломанная ссылка на контролёра срезов чинится. Если поиск по смыслу в среде недоступен — Grep и Glob. В плане анализа «быстрый explore» становится обычным вызовом. Картограф не читает скилл карты целиком. Журнал агентов в шапке указывает, где живёт таблица моделей. Стайл-гайд оркестратор читает только по процитированному разделу.
5. Учебные литералы реальных проектов в `.cursor/**` заменяются нейтральным словарём kit. Allow-list префиксов в антипаттерне именования не трогаем: это механизм, не пример.

## Capabilities

### New Capabilities

- `kit-project-neutrality`: поставка `.cursor/**` не содержит имён реальных проектов в фильтрах и в учебных примерах; охват маркеров — по сегментам `cf`/`cfe`.

### Modified Capabilities

- `chat-surface-clarity`: развилка после последнего среза смотрит на `cfe` / `mixed` против пустого / `cf` (не ярлык выгрузки одного заказчика).
- `scenario-map-canvas`: предложение схемы после описания ЗНИ считает порог по правилам выбранного средства; согласие — тот же один отчёт.
- `always-apply-context-budget`: скилл команды читается на входе сессии; страховка обрезки с именами служебных карточек — в always-apply правиле сессии; строка диспетчера карты — cue.
- `delegation-safeguards`: ссылка на шаблон контролёра срезов, запасной поиск без смыслового инструмента, вызов generic explore без режима `fast`, картограф без полного чтения скилла карты, чтение стайл-гайда по цитате.

## Impact

- Kit: скилл реализации и статуса, глоссарий, чеклист поставки, описание ЗНИ, правило сессии, диспетчер гейтов, шаблоны и эталоны, команды knowledge/extend, документы стиля и ревью.
- Продуктовый код 1С и конфигурация не меняются.
- Вне scope: приёмка и архив соседних ЗНИ; потолок сценариев карты; сжатие оболочки панели; вынос префиксов `pav_` / `lvv_` / `пр_` из allow-list; архивные отчёты в `openspec/changes/archive/**`; вендорские имена объектов 1С.

## Scope

- In scope: фильтр охвата маркеров; словарь `cf` / `cfe` / `mixed`; порог схемы после описания; вход сессии и обрезка скилла; cue карты в диспетчере; ссылки и fallback инструментов; нейтральные примеры в `.cursor/**`.
- Out of scope: прикладная конфигурация; открытые или уже архивированные ЗНИ про карту и развилку (их не принимать и не переархивировать); `openspec/changes/archive/**`; allow-list AP-031.

## Acceptance Criteria

1. В скилле реализации нет путей чужой выгрузки как фильтра. Kit-only после «принято» — архив без предрелиза. ЗНИ с модулями расширения в задачах — три слова.
2. После описания порог схемы совпадает со средством карты; в скилле описания нет фразы «после поставки соседней ЗНИ».
3. Правило сессии: полный скилл — на первом ходе; на follow-up — протокол без повторного Read. В диспетчере «покажи схему» остаётся указателем.
4. Ссылка контролёра срезов открывается. В `.cursor/**` нет имён из списка утечки (Павлик, ЭДО ПАО, ЭДО и ЭА, ДО3 Демо, КонтурДиадок, do2-pavlik, nastroyka-knopok-processov).
