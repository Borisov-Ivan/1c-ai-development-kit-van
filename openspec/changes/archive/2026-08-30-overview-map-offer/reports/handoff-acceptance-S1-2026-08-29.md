### 1. Что реализовано

После описания ЗНИ в чате всегда есть строка следующего шага. Если по названной ЗНИ уже лежит отчёт разбора со связями, в этой же строке может появиться вариант схемы с конкретным «что станет видно». Панель сама не открывается. По согласию сборщик берёт тот же один отчёт, на котором прошла проверка; этапы поставки из файла описания узлами не становятся. Отдельной команды карты нет.

### 2. Что проверить СЕЙЧАС

**Primary (обязательно):** вызвать описание ЗНИ, у которой уже есть отчёты разбора со связями → в чате есть вариант схемы с фразой «что станет видно», панели нет → ответить согласием → открывается панель из того же отчёта, на котором прошла проверка; узлы не повторяют этапы поставки.

Опционально: описание ЗНИ только с постановкой (строка шага есть, варианта схемы нет); плоский набор без формы связей; отказ «без карты» и повторное описание в той же сессии; прямая просьба «покажи карту сценария» после описания без указания пути.
