## Why

При создании ЗНИ, где правят только модуль формы (номера в заголовках колонок, состав полей и кнопок не трогают), чат всё равно спрашивает «вручную / автоматически / программно». Пропуск даёт «вручную»: на реализации ждут выгрузку из Конфигуратора, хотя разметку не меняют.

## What Changes

1. **BREAKING.** Вопрос «как поставляем форму» на этапе design больше не обязателен для каждой формы в области задачи. Если после стабилизации списка доказано: для этой формы в работе только модуль, разметки нет — выбора из трёх нет, в карточке ЗНИ сразу поставка программно. Форму из списка не выкидывать: иначе на проверке будет дыра режима.
2. Если в задачах есть разметка формы (поля, кнопки, выгрузка разметки, Конфигуратор) или способ неясен — вопрос как сейчас. «Автоматически» молча не выбирать. Пустой ответ на **заданный** вопрос по-прежнему «вручную».
3. Справка kit (FAQ, быстрый старт) описывает пропуск: вопрос не всегда задаётся.
4. Сохраняется: один вопрос выбора за ход; макет в new не спрашивается; kit без форм — без вопроса, режим «не применимо»; записанный режим при продолжении ЗНИ не переспрашивают и не перетирают.

## Impact

- Kit: правило вопроса режима формы, цикл создания ЗНИ на design, FAQ и быстрый старт. Продуктовый код 1С и конфигурация не меняются.
- Вне scope: политика макета; новый набор значений режима; молчаливый выбор «автоматически»; правка apply/verify, если в карточке уже записан валидный режим.

## Scope

- In scope: правило вопроса, цикл `/opsx:new` на design, FAQ, быстрый старт, дельта требования `split-form-layout-modes`.
- Out of scope: прикладная конфигурация; макеты; новые значения режима; silent «автоматически»; смена default пропуска на заданном вопросе.

## Acceptance Criteria

1. На постановке «только модуль панели, разметку не трогаем» выбора из трёх нет; в карточке ЗНИ для этой формы — программно.
2. На «доработать форму» без ясности и на правке разметки вопрос остаётся; пустой ответ — вручную.
3. Две формы (модуль и разметка) получают разные режимы, без копирования.
4. Макет в new по-прежнему не спрашивается. Продолжение ЗНИ с уже записанным режимом его не перетирает.
