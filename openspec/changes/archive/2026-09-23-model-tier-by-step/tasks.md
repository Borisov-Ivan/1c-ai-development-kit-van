# Срез S1: Готовность задач на модели чата

**Сценарий:** на проверке с рискованными задачами готовность задач запускается на модели чата, а обычный архитектурный шаг остаётся на тяжёлой.

**Primary acceptance:** открыть таблицу шагов в правиле назначения и увидеть, что готовность задач вызывается без явной модели, а соседний обычный архитектурный шаг по-прежнему назван тяжёлой моделью. Строка роли только ссылается на таблицу.

**Приёмка:** ручная сверка текста правил и скиллов kit (ИБ и Конфигуратор не нужны).

**Связь со spec:** Requirement «Мэппинг ролей на актуальные модели» — Scenario «Готовность задач на модели чата», Scenario «Сбой единственного вызова готовности задач», Scenario «Вызов архитектора без ошибки enum», Scenario «Команда на Grok 4 без смены чата», Scenario «Рантайм свободен от мёртвых слагов»; Requirement «Самосверка enum перед вызовом с model=» — Scenario «Слаг таблицы отсутствует в enum сборки»; Requirement «Двухшаговая цепочка вызова» — Scenario «Согласованность описаний цепочки».

**Зависимости:** нет.
