## Результат

В начале описания каждой новой задачи есть раздел «Результат»: короткий абзац о том, что можно сделать и где это видно. Абзац появляется сам при создании задачи, его можно скопировать в колонку «Результат» отчёта. Если к сдаче видимое поведение другое, тот же абзац поправляется при закрытии задачи. Уже сданные задачи этот раздел сами не получают.

## Why

Чтобы заполнить колонку «Результат» в отчёте, приходится отдельно просить кратко сформулировать итог. В описании задачи такого абзаца нет, копировать неоткуда.

## What Changes

1. При создании задачи в начало описания добавляется раздел «Результат».
2. В разделе 2–4 предложения: что можно сделать и где это видно.
3. При закрытии задачи абзац обновляется, если видимое поведение разошлось с текстом на старте.
4. Уже закрытые описания задач раздел сами не получают.
5. Обзор для согласования с заказчиком этот абзац не подставляет и описание задачи не меняет.

## Capabilities

### New Capabilities

- `proposal-result`: в описании задачи есть короткий абзац «Результат» для колонки отчёта. Он пишется при создании задачи и поправляется при закрытии, если видимое поведение изменилось.

### Modified Capabilities

## Impact

Меняются правила создания и закрытия задачи и шаблон описания задачи. Конфигурация 1С не меняется. Уже сданные задачи не переписываются. Обзор для согласования остаётся отдельным файлом.

## Acceptance Criteria

1. У новой задачи в начале описания есть раздел «Результат» из 2–4 предложений о видимом поведении, без путей к файлам, номеров шагов и имён команд.
2. Абзац можно скопировать в колонку «Результат» отчёта без отдельной просьбы переформулировать.
3. Если к закрытию видимое поведение другое, в том же разделе лежит обновлённый абзац.
4. У задачи, закрытой до этой правки, раздел сам не появляется.
