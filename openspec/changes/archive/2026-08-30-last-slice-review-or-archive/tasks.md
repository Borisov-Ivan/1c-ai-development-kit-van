# Срез S1: Развилка после последнего среза

**Сценарий:** разработчик принимает последний срез ЗНИ, в которой есть код расширения, и в чате получает один вопрос с тремя словами — `ревью`, `архив`, `стоп`; слово `ревью` даёт готовую команду предрелизного ревью, ЗНИ остаётся активной.
**Primary acceptance:** ЗНИ с кодом расширения → принять последний срез фразой «принято» → в чате три слова, ничего не заархивировано → ответить `ревью` → одна команда `/release-review <имя>`, каталог ЗНИ на месте.
**Приёмка:** ручной прогон чата на ЗНИ с кодом расширения; статическая часть — сверка текста скилла реализации, памятки ревью, памятки оформления финала и шаблона проверки постановки задачами среза.
**Связь со spec:** Requirement «Last-slice acceptance offers prerelease or archive» — Scenario «Последний срез — развилка из трёх слов», Scenario «Ответ ревью даёт команду предрелиза», Scenario «Ответ архив без изменений», Scenario «Ответ стоп без изменений», Scenario «Без кода расширения слова ревью нет», Scenario «Возврат в сессию — та же развилка», Scenario «Карточка завершения — та же развилка», Scenario «Проверка постановки после apply не меняется».
**Зависимости:** нет.
**Режим apply:** mechanical

## 5. Приёмка

- [x] S1.accept Принять срез S1 «Развилка после последнего среза» — после последнего среза чат предлагает ревью или архив одним вопросом:
  - **Primary (обязательно):** на ЗНИ с кодом расширения принять последний срез фразой «принято» → в чате три слова `ревью` / `архив` / `стоп`, ничего не заархивировано → ответить `ревью` → в чате одна команда `/release-review <имя>`, каталог ЗНИ на месте (Scenario «Последний срез — развилка из трёх слов», Scenario «Ответ ревью даёт команду предрелиза»)
  - Scenario «Ответ архив без изменений» (опционально): ответить `архив` на развилку — архивация проходит в той же сессии и заканчивается тем же тонким итогом, что до этой ЗНИ
  - Scenario «Ответ стоп без изменений» (опционально): ответить `стоп` на развилку — сессия завершается, ЗНИ не тронута
  - Scenario «Без кода расширения слова ревью нет» (опционально): принять последний срез ЗНИ только по правилам kit — в чате прежний вопрос с ответами `архив` и `стоп`, слова `ревью` нет
  - Scenario «Возврат в сессию — та же развилка» (опционально): вернуться в сессию реализации и отметить последний срез принятым — в чате та же развилка, а не отдельная строка только с командой архива
  - Scenario «Карточка завершения — та же развилка» (опционально): войти в реализацию ЗНИ с кодом расширения, где все срезы уже приняты — вместо строки с командой архива печатается та же развилка
