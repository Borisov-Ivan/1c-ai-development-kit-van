# Spec Delta

## MODIFIED Requirements

### Requirement: Запрет built-in Explore для 1С-кода
Обследование кода 1С, включая один модуль и короткий текст ошибки без трассы, SHALL идти только через проектного обследователя. Встроенный общий поиск для этих путей запрещён. Если обследователь недоступен, оркестратор SHALL остановиться и сказать об этом. Сам по коду он SHALL NOT искать. Для markdown и файлов данных вне кода 1С общий поиск остаётся.

#### Scenario: Обследование BSL при недоступном кастомном агенте
- **WHEN** `onec-code-explorer` недоступен, а требуется обследование `.bsl`
- **THEN** оркестратор останавливается и сообщает пользователю; built-in explore не вызывается

#### Scenario: Не-1С файлы
- **WHEN** требуется анализ markdown-отчёта или файла данных вне 1С-контента
- **THEN** generic explore допустим согласно context-strategy

#### Scenario: Один модуль тоже обследование
- **WHEN** нужно понять поведение одного модуля `.bsl`
- **THEN** вызов идёт проектному обследователю; оркестратор модуль сам не читает

#### Scenario: Короткий текст ошибки без трассы
- **WHEN** есть только текст ошибки 1С и нет файла трассы
- **THEN** разбор идёт проектному обследователю с узким заданием; оркестратор по коду сам не ищет
