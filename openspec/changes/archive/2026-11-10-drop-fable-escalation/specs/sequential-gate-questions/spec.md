# Spec Delta

## ADDED Requirements

### Requirement: Пакет продуктовых развилок остаётся одним актом
Пакет независимых продуктовых развилок, который договор повторной проверки уже требует одним сообщением, SHALL оставаться одним актом выбора. Проверка «два вопроса выбора в одном ответе» этот пакет SHALL NOT разрезать. Вопрос про маркер автора и вопрос про способ поставки формы SHALL оставаться в разных сообщениях.

#### Scenario: Две продуктовые развилки уходят одним сообщением
- **WHEN** при создании заявки известны две развилки наблюдаемого поведения
- **THEN** заказчик получает одно сообщение с двумя нумерованными вопросами, и ответ не пересобирается в один вопрос

#### Scenario: Маркер и форма не сливаются
- **WHEN** в одном черновике стоят вопрос про маркер автора и вопрос про способ поставки формы
- **THEN** такое сообщение не уходит; вопросы задаются разными ходами
