## Резюме для разработчика

Срез S2 можно отдавать на приёмку. Ось постановки не менялась, повторный независимый разбор не назначался. Это сдача последнего среза: рабочие задачи обоих срезов закрыты, обе приёмки открыты. Срез S1 отложен до этого теста, доработок у него нет.

Обследование кода в перечне агентов и в таблице остановок больше не ограничено тремя модулями. Написание, обследование и трасса после сбоя не вызываются второй раз тем же способом. Команда дописывания не держит свой список шагов. Пакет продуктовых развилок проверка одного вопроса не разрезает.

**Следующий шаг:** финальный тест. На карточке основной осмотр среза S2 «Один хозяин на шаг» и основной осмотр среза S1 «Сильные шаги на Opus».

## Сверка реализации

- В шапке правила назначения модель передаётся, только если строка роли её задаёт. Фраза про два шага не покрывает написание, обследование и трассу: сбой вызова без отдельной модели второй такой же вызов не запускает. Простая готовность задач без трёх особых поводов остаётся без отдельной модели.
- Перечень агентов и таблица остановок говорят «обследование кода» без порога «3+ модулей». Модель шага архитектора берётся из строки шага, в том числе когда отдельной модели нет. Шапка шаблона проверки частей заявки не называет файл агента источником модели. В примерах ревью есть старшая модель семейства Gemini, а если семейства в списке нет — параметр не передаётся. В примере упрощения стоит `composer-2.5-fast`.
- Короткий текст ошибки без трассы идёт обследователю. Оркестратор по коду сам не ищет. Шаг про стек после трассы не менялся.
- В таблице типов задач диспетчера порог «3+ модулей» снят: строка — «Любое обследование кода». Новый срез не открывался. Абзац про запрет встроенного поиска и порог нуля чтений на месте. Разбор не-1С файлов по-прежнему в стратегии контекста: для markdown и файлов данных общий поиск допустим.
- Команда дописывания не содержит нумерованного списка шагов и не назначает проверку после каждого дописывания. Предупреждение, что подпись откроется заново, из команды ушло.
- Пункт поведения дозавершения: задача по подписанному срезу открывает следующий срез, подпись сама не снимается.
- В команде создания вопрос про маркер не назван вторым действием. Пример снимка не подставляет запуск разработки, когда шаг другой.
- В шапке обзора сборщик манифеста не вызывается.
- Строка про свежую передачу включает чтение файла передачи. Список шаблонов при обрезке скилла берётся из правила входа команды.
- Ссылки на разделы бюджета, которых нет в коротком тексте, называют полное тело. Таблица лимитов в короткий текст не копировалась.
- Проверка «два вопроса выбора» не разрезает пакет продуктовых развилок. Вопрос про маркер и вопрос про форму остаются разными ходами.
- Пять мест проверки нескольких частей и фразы про профиль GPT-5.6 не переписывались.
