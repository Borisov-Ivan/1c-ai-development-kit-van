# Проходы по хвостам набора, 2026-11-10

Четыре независимых прохода по живым правилам, скиллам и договорам. Архив, справочники платформы и журнал агентов не читались как действующие инструкции.

## Взято в срез S2

- Перечень агентов говорит «обследование 3+ модулей», правило делегирования — любое обследование, порог ноль чтений. Хозяин — делегирование.
- Короткий текст ошибки без трассы предлагает искать по коду самому. Хозяин — обследователь.
- Фраза «цепочка каждой роли — два шага» спорит с цепочкой написания, обследования и трассы: там первый шаг уже без отдельной модели.
- Шапка шаблона проверки частей заявки называет файл агента источником модели. Ниже в том же файле источник — правило назначения.
- Пример вызова ревью и упрощения не содержит модель, которую задаёт строка роли.
- Команда дописывания держит свой список шагов, всегда зовёт проверку и предупреждает, что подписанная приёмка откроется заново. Скилл и правила вставки говорят иначе: по умолчанию следующий срез.
- Команда создания называет вопрос про маркер вторым действием раньше шагов скилла.
- Договор одного вопроса выбора режет пакет продуктовых развилок, который другой договор уже требует одним сообщением. Вопрос маркера и вопрос формы остаются разными ходами.
- Указатели разделов бюджета называют короткий текст, в котором этих разделов нет.

## Не взято

- Копировать таблицу лимитов в короткий текст. Это утяжелит каждый ход. Чинются указатели.
- Строка глубокого разбора без тяжёлого признака и абзац про независимый разбор описывают разные шаги.
- Лимит карточки уже не режет содержание проверки.
- Проверка нескольких частей: правило уже на Opus, основной договор ещё на GPT. Это соседняя заявка.
- Архив и журнал агентов остаются историей.
