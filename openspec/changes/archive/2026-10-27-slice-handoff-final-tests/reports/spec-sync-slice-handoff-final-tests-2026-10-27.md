# Перенос спецификаций: slice-handoff-final-tests

**Дата:** 2026-10-27

## chat-surface-clarity

- Изменено: «Apply pause-wait is a navigator card» — первая строка паузы без «готов» и без финального теста.
- Изменено: «Last-slice acceptance offers prerelease or archive» — вопрос архива после среза, за которым не остаётся открытых работ и открытых приёмок. Прежние сценарии слов `ревью` / `архив` / `стоп` сохранены. Добавлены два сценария: последний по порядку при открытых доработках вопрос не открывает; финал раннего среза открывает его в том же ходе.
- Изменено: «Карточка приёмки показывает место среза» — место словами, финальный тест по открытым задачам.
- Изменено: «Приёмка без прогона остаётся видимой» — строка на карточке финального теста, не на последнем по порядку, пока у раннего открыты доработки.
- Добавлено: «Сдача называет состав среза и основные тесты».

## kit-protocol-coherence

- Изменено: «Конец среза один» — три ответа, пока финал впереди; на финале два; «Принять» закрывает показанные срезы.
- Изменено: «Старт разработки читает итог проверки» — предупреждение после ответов; на финале нет вопроса «какой срез».

## ADR

- ADR-0001 обновлён: блок основных тестов вне потолка короткой сдачи. Новый ADR не создавался.
