# Срез S1: Текст сдачи в чате

**Сценарий:** разработчик получает сдачу и по сообщению видит место среза, идёт ли финальный тест, что вошло в срез и какие основные тесты пройти.
**Primary acceptance:** на заявке из одного среза в чате сказано, что это финальный тест, есть основной тест и нет ответа «отложить до финального теста».
**Приёмка:** ручная сверка трёх карточек с правилами чата.
**Связь со spec:** Requirement «Карточка приёмки показывает место среза», Requirement «Сдача называет состав среза и основные тесты», Requirement «Apply pause-wait is a navigator card» (`chat-surface-clarity`); Requirement «Конец среза один», Requirement «Старт разработки читает итог проверки» (`kit-protocol-coherence`).
**Зависимости:** нет

## 6. Приёмка

- [x] S1.accept Принять срез S1 «Текст сдачи в чате» — по сообщению сдачи видно место среза, идёт ли финальный тест, что вошло и какие основные тесты пройти:
  - **Primary (обязательно):** на заявке из одного среза в чате сказано, что это финальный тест, есть основной тест и нет ответа «отложить до финального теста»
  - Scenario «Передача предлагает три ответа» (опционально): на втором из трёх сказано, что финал впереди, и есть ответ «Отложить до финального теста»
  - Scenario «Финал собирает тесты ещё не принятых срезов» (опционально): на финальном тесте основной тест другого среза с закрытыми работами и открытой приёмкой стоит в том же сообщении, с именем среза
  - Scenario «Последний срез при открытых доработках раннего» (опционально): на последнем из трёх, пока у первого открыты доработки, сказано, что финал после них, и есть ответ «Отложить до финального теста»
  - Scenario «Доработка раннего закрыла последние работы» (опционально): сдача первого среза после таких доработок — финальный тест, в сообщении есть основной тест отложенного последнего, ответа «отложить» нет
  - Scenario «Принять на финале закрывает показанные срезы» (опционально): ответ «Принять срез» закрывает этот срез и другой показанный, вопроса «какой срез» нет
  - Scenario «Неполная карточка финала не уходит» (опционально): карточка финала без блока теста среза с закрытыми работами и открытой приёмкой не отправляется
  - Scenario «Принять на финале пишет записи приёмки каждого показанного среза» (опционально): у каждого закрытого среза появляются отметка приёмки и запись решения, как при обычном принятии
  - Scenario «Единственный срез — финальный тест» (опционально): в образце одного среза нет дроби «1 из 1»
  - Scenario «Пустой список отложенных не пишется» (опционально): в образце одного среза нет блока «отложенных тестов нет»
  - Scenario «Полный перечень лежит в файле сдачи» (опционально): раздел «Что проверить сейчас» содержит полный чеклист, а не отсылку к списку задач
  - Scenario «Своя фраза «отложить» на финале не откладывает» (опционально): по правилу разбора ответа приёмка остаётся открытой и сказано, что финального теста дальше нет
  - Scenario «Пауза в работе не называет финальный тест» (опционально): в правиле паузы с объектами нет слов «готов» и «это финальный тест»
  - Scenario «Пакет называет сдачу без одного номера» (опционально): конечная карточка пакета, после которого открытых работ не остаётся, называет финальный тест без «N из M»
  - Scenario «Проверки не было» (опционально): предупреждение стоит после ответов и не становится отдельным выбором
