# Code Exploration: отчёты исследования → каталог ЗНИ и вводные в отчёте

## Вводные

- **Исходный запрос:** любая работа над ЗНИ начинается с исследования; результат кладётся в `temp`; при создании ЗНИ файл остаётся снаружи каталога. Нужно, чтобы при создании ЗНИ он переезжал в каталог задачи — там фактура для последующего анализа. Дополнение: в отчёте не оказалось, с каким объектом была проблема; вводные тоже фиксировать.
- **Область:** kit (скиллы исследования и создания ЗНИ), не конфигурация 1С.
- **Объекты / пути из постановки:** `.cursor/skills/openspec-new-change/`, `temp/reports/`, `temp/explore-handoff-*.md`.
- **Вопрос:** какие файлы исследования должны оказаться в каталоге ЗНИ, и какие вводные должны быть в самом отчёте, чтобы при следующем разборе не терялись объект и фактура.

## Свод

Два независимых разрыва, оба подтверждены текстами скиллов:

1. Создание ЗНИ забирает **текст** блока постановки из чата (или опциональный handoff), **не** переносит файлы отчётов из `temp`.
2. Бриф после «да» в файл не пишется; шаблон отчёта обследования не требует шапки «с чем пришли» (исходный текст, объект, слоты брифа). В отчёте — найденный код, не вводные заказчика.

(`.cursor/skills/openspec-new-change/SKILL.md`: приоритет источников 1b, правило «Explore context MUST NOT be used only for naming»; шаблон `templates/handoff-contract.md` — только поля блока.)

3. **Verified:** каталог `temp/` в `.gitignore` — отчёты исследования не попадают в репозиторий, пока не окажутся в каталоге ЗНИ.

## Гипотезы

- **Гипотеза:** при создании ЗНИ достаточно переносить отчёты этой сессии (по теме/slug за окно, согласованное с 48ч handoff), а не весь `temp/reports`. Подтвердит: правило отбора в скилле new. Опровергнет: пользователь явно держит несколько параллельных исследований в одном temp.
- **Гипотеза:** шапка «Вводные» в отчёте должна дублировать слоты брифа (симптом, вопрос, объекты/пути из «Контекст») и исходную формулировку пользователя — этого достаточно, чтобы по файлу вспомнить объект без чата. Подтвердит: приёмка «открыл отчёт — вижу объект и исходный запрос». Опровергнет: нужны ещё вложения (трасса, скрин) списком в той же шапке.
