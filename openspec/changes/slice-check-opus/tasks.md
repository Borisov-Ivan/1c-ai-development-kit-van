# Срез S1: Проверка нескольких срезов на Opus 5

**Сценарий:** в заявке несколько срезов, и проверка плана идёт на старшей модели Opus 5, даже если в этот запуск попал один срез.

**Primary acceptance:** открыть правило назначения и увидеть, что проверка заявки из нескольких срезов описана старшей моделью семейства Opus, мажор 5, а заявка из одного среза — без отдельной модели.

**Приёмка:** чтение правила назначения и профиля чата. Конфигурация 1С не нужна.

**Связь со spec:** Requirement «Мэппинг ролей на актуальные модели» — Scenario «Сверка одного среза на модели чата», Scenario «Сверка нескольких срезов на Opus 5», Scenario «В списке нет Opus 5 для сверки срезов»; Requirement «Самосверка enum перед вызовом с model=» — Scenario «Слаг таблицы отсутствует в enum сборки».

**Зависимости:** нет.

  1. Строка роли контроля согласованности срезов (`openspec-quality-controller`): в заявке один срез — без отдельной модели; срезов больше одного — старшая модель семейства Opus, мажор 5, даже если в этот запуск попал один срез; такой модели нет — без отдельной модели, одна строка предупреждения, другое семейство не подставлять.
  2. Абзац под таблицей ролей о профиле GPT-5.6 и роутере профилей удалить. Вместо него: исключение живёт в строке роли, не во второй таблице; слаг берётся правилом старшинства по строке «Контроль нескольких срезов» раздела «Старшая модель семейства»; цепочка этой роли ниже исключение не затирает.
  3. В таблицу раздела «Старшая модель семейства» добавить строку «Контроль нескольких срезов»: семейство Opus, мажор 5; пусто — вызов без отдельной модели, одна строка предупреждения, другое семейство не подставлять, запас через Gemini и Fable не использовать. Фразу «контроль нескольких срезов этим отбором семейства не выбирается» удалить.
  4. Раздел самосверки: для заявки, в которой срезов больше одного, — старшая модель семейства Opus, мажор 5. Пустой отбор Gemini у ревьюера и пустой отбор Opus 5 у контроля нескольких срезов ведут к вызову без отдельной модели. Ревьюеру Opus не подставляется; контролю срезов Gemini и Fable не подставляются. Фразу «Opus не подставляется» у проверки срезов убрать.
  5. Цепочка этой проверки, пункт про несколько срезов: слаг старшей модели Opus 5 по разделу «Старшая модель семейства».

  Таблицу шагов архитектора не трогать, проверку срезов в неё не добавлять. Лестница «нет Fable — старшая Opus 5» к этой роли не относится; сбой вызова на Opus переходит к вызову без отдельной модели и Fable не включает. Перед вызовом проверки срезов строка «Разбор постановки (Opus 5)» и любая другая строка модели в чат не пишется — допустима только строка предупреждения при пустом отборе. Строки ревью кода, разбора постановки, написания кода, обследования, трассы, упрощения и рекомендации чата не менять. Критерий: в файле нет назначения проверки срезов на GPT-5.6; по тексту закрыты Scenario «Сверка одного среза на модели чата», «Сверка нескольких срезов на Opus 5», «В списке нет Opus 5 для сверки срезов», «Слаг таблицы отсутствует в enum сборки».
