# ADR-0019: Одна оставшаяся строка помечается одним хвостом

**Статус:** Load-Bearing
**Дата:** 2026-11-10
**Область:** kit / пометка изменения
**Источник:** openspec/changes/archive/2026-11-10-handoff-empty-explore/reports/architecture-invariant-extraction-2026-11-10.md
**Load-bearing:** yes
**Protects-invariants:**
  - "Одна оставшаяся строка кода получает один хвост, равный уже собранной открывающей пометке; пара остаётся для соседних строк, новой процедуры, строки запроса, строки со своим комментарием и удаления без несущей строки; текст открывающей пометки не меняется"

## Контекст

Полная пара вокруг одной оставшейся строки кода громоздка. Короткий хвост без фразы открывающей пометки не говорит, кто, когда и зачем правил. Хвост внутри текста запроса и на строке удаления перехвата попадает в сверяемый текст.

## Решение

Одна оставшаяся строка кода вне строковой константы и без своего смыслового комментария получает один хвост, равный уже собранной открывающей пометке. Второй служебной строки над ней нет, закрывающей пометки под ней нет. Соседние строки одного изменения, новая процедура, строка запроса, строка со своим комментарием и удаление без несущей строки остаются парой. Текст открывающей пометки не меняется. Уже стоящие пары не переписываются.

## Альтернативы

| Вариант | Почему отклонён |
|---------|-----------------|
| Пара на любую правку, включая одну строку | Длинная пометка сверху и закрытие под одной строкой |
| Хвост короче открывающей пометки | Теряются автор, дата или причина |
| Перенос пометки на директиву вставки или на удалённый текст | Пометка не стоит на строке, которая осталась, либо попадает в сверяемый текст |

## Последствия

- Положительные: одна строка помечена тем же смыслом, что и пара, без второй служебной строки.
- Отрицательные: хвост длиннее короткой пометки без фразы.
