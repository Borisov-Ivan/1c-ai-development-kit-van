# ADR-0017: Команда новой заявки из исследования только рядом с блоком

**Статус:** Load-Bearing
**Дата:** 2026-11-10
**Область:** kit / финал разбора
**Источник:** openspec/changes/archive/2026-11-10-handoff-empty-explore/reports/architecture-extend-coherence-2026-10-23.md
**Load-bearing:** yes
**Protects-invariants:**
  - "Исследование с шагами показывает команду новой заявки только рядом с блоком постановки; видимый каталог без требований продолжается тем же именем, заявка с требованиями и задачами дописывается; доработка без обследования не переписывается"

## Контекст

Исследование, которое понимает и исправляет, показывало команду новой заявки без блока постановки. То же имя использовалось и для продолжения недособранной заявки, поэтому запрет «без блока не создавать» мог закрыть и дозавершение.

## Решение

Команду новой заявки исследование показывает только в сообщении, где уже напечатан блок постановки. Это не касается доработки без шагов исследования. Продолжение видимого каталога без требований идёт тем же именем и блока не требует. Если требования и список задач уже есть, шаг — дописать эту заявку. Невидимый каталог с именем считается созданием и требует блока.

## Альтернативы

| Вариант | Почему отклонён |
|---------|-----------------|
| Блок обязателен на любом маршруте, включая доработку без обследования | Отменяет право такого маршрута идти в создание сразу |
| Всегда дописывать открытую заявку той же области | Для заявки без требований дописывание не проходит остановленную цепочку |

## Последствия

- Положительные: согласованная постановка не собирается заново коротким подтверждением.
- Отрицательные: продолжение без блока зависит от того, виден ли каталог в списке открытых заявок.
