# ADR-0015: Абзац «Результат» пишется при создании и сверяется при закрытии

**Статус:** Accepted
**Дата:** 2026-10-05
**Область:** kit / описание задачи
**Источник:** openspec/changes/archive/2026-10-05-proposal-result/reports/architecture-new-2026-10-04.md
**Load-bearing:** no

## Контекст

Колонку «Результат» в отчёте приходилось просить отдельно: в описании задачи не было короткого абзаца, который можно скопировать. Абзац на старте описывает обещанное поведение, а в отчёт нужен сданный итог.

## Решение

У новой задачи описание начинается с раздела «Результат»: 2–4 предложения о том, что можно сделать и где это видно. Раздел пишет то же правило, которым при создании дописываются автор и режим форм. Источник — «Что менять» и «Приёмка»; для дефекта ещё «Симптом». При закрытии абзац сверяется со сданным поведением и переписывается на месте, только если обещает несданное или не называет появившийся видимый итог. Уже сданное описание без этого раздела его не получает. Обзор для согласования описание не меняет.

## Альтернативы

| Вариант | Плюсы | Минусы | Почему отклонён |
|---------|-------|--------|-----------------|
| Писать абзац только при создании | Проще | В отчёт может уйти текст, который уже не совпадает со сданным | Сверка при закрытии нужна |
| Просить формулировку отдельно в чате | Ничего не менять в описании | Копировать неоткуда | Это и была исходная боль |
| Другое имя раздела | — | Не совпадает с колонкой отчёта | Имя «Результат» видно сразу |

## Последствия

- Положительные: абзац для колонки отчёта появляется сам и к сдаче совпадает с видимым итогом.
- Отрицательные: при расхождении поведения закрытие переписывает абзац молча, без строки в итоге.
- Нейтральные: место блока автора сразу после «зачем» не меняется. Граница текста для человека и текста для агента (ADR-0001) не отменяется.
