# ADR-0016: Подтверждение на создании с именем считается постановкой

**Статус:** Load-Bearing
**Дата:** 2026-11-10
**Область:** kit / создание заявки
**Источник:** openspec/changes/archive/2026-11-10-handoff-empty-explore/reports/architecture-2026-10-23-handoff-empty-explore.md
**Load-bearing:** yes
**Protects-invariants:**
  - "Подтверждённый ответ на создании с именем считается постановкой и снимает остановку; подтверждение пути без имени постановкой не считается; недособранная заявка продолжается тем же именем"

## Контекст

Создание заявки с именем записывало описание без блока постановки и останавливалось до требований. Текст остановки звал пустой разбор, а пустой разбор тему не продолжал. Повтор того же имени снова попадал в ту же остановку, потому что подтверждённое описание в условие остановки не входило.

## Решение

Постановку для пути с именем собирает создание. Короткое подтверждение до записи описания считается постановкой и снимает остановку. Если описание уже есть, а требований нет, подтверждение строится из этого описания и заявка продолжается тем же именем. В тексте остановки одна команда продолжения с именем. Подтверждение пути без имени постановкой не считается.

## Альтернативы

| Вариант | Почему отклонён |
|---------|-----------------|
| Бриф либо блок из разбора | Два места отвечают за один артефакт, остановка после брифа повторяется |
| Возврат пустым разбором | Пустой разбор тему не помнит |

## Последствия

- Положительные: согласованное описание не теряется между созданием и следующим ходом.
- Отрицательные: путь без имени по-прежнему может остановиться и попросить блок.
