# sequential-gate-questions

## Purpose

Один вопрос выбора за ход оркестратора при постановке ЗНИ.

## Requirements

### Requirement: One selection question per orchestrator turn

При создании или уточнении ЗНИ оркестратор SHALL задавать не более одного вопроса с взаимоисключающим выбором (карточка выбора или нумерованный список вариантов) в одном сообщении и SHALL дождаться ответа пользователя перед следующим таким вопросом.

#### Scenario: Metadata question without Mode Gate in same message

- **WHEN** оркестратор задаёт вопрос про описание маркера автора при `/opsx:new`
- **THEN** в том же сообщении нет вопроса про способ поставки управляемой формы

#### Scenario: Second gate only after answer

- **WHEN** пользователь ответил на вопрос Metadata Gate и для ЗНИ нужен вопрос про режим формы
- **THEN** вопрос про режим формы приходит отдельным последующим сообщением (на этапе design)

#### Scenario: Dual selection questions blocked

- **WHEN** протокол self-check перед отправкой обнаруживает два или более вопроса выбора в одном черновике ответа
- **THEN** оркестратор не отправляет такое сообщение и пересобирает ответ с одним вопросом
