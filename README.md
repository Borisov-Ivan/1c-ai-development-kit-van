# kit-van — ветка поставки

Здесь лежит только то, что ставится в проект 1С: каталог `.cursor/` и файл `AGENTS.md`.

**Версия поставки:** 2026-08-27 · исходный коммит разработки `8711292` (ветка `develop`)

## Как поставить в проект

```bat
git submodule add -b main https://github.com/Borisov-Ivan/1c-ai-development-kit-van vendor/kit-van
tools\sync-kit.cmd
```

Полная инструкция, скрипт синхронизации и обновление нескольких проектов — `.cursor/docs/kit-as-submodule.md` в этой же ветке.

## Что здесь не лежит

Разработка kit (спеки, ADR, заявки на изменение, документация 1С, утилиты) живёт на ветке `develop`. Эта ветка обновляется только публикацией из `develop` и не принимает слияний.
