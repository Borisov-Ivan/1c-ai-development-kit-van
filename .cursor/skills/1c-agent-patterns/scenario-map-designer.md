# Картограф карты сценария (шаблон промпта)

Роль **не** 1С-агент. 1С-контент (`src/**`, `.bsl`, XML метаданных) сюда не отдавать — обследование кода только `onec-code-explorer`.

Вызов: `Task(subagent_type="onec-scenario-map-designer")` **без** `model=`. Контракт агента — `.cursor/agents/onec-scenario-map-designer.md`. Когда рисовать — `.cursor/skills/scenario-map-canvas/SKILL.md`.

Картограф возвращает **манифест данных**. Файл панели регистрирует родительский агент сессии по [`fixtures/canvas-shell.md`](../scenario-map-canvas/fixtures/canvas-shell.md). Ссылка в чат критерием успеха не является.

```markdown

Собрать манифест панели карты сценария из источника и диапазонов: шапка, узлы со связями, виды, стартовый узел, режимы и аннотации по контракту скилла. Файл не писать.

## Ограничения
Не править src/** и openspec/**. Не обходить код шире переданных диапазонов. Не выдумывать рёбра. Расхождения отчётов — кандидаты, не разрешение достроить ребро. Отсутствие отношения — аннотация с доказательством, не ребро. Аннотацию без доказательства не возвращать. Порядок прохода — relation follows, не причинность. Если доказанных связей не хватает или вопрос шапки не отвечается полотном после двух кругов — check: cannot-publish. Круг ремонта не больше двух. Поля file_path нет.

## Критерий готовности
```
