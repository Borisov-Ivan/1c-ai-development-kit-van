# Шаблон чата `/opsx:verify` (без флагов, без кодов выбора `1a`)

Использовать **один** из двух вариантов ниже. Не смешивать. Не добавлять блоки «Решение N», «От вас нужно», «Как ответить». Не требовать от пользователя ответа кодами вида `<N>a`:

---

## Тихий вариант — когда фильтр новизны допускает завершить без нового файла отчёта

`ЗНИ: <имя-change> — Готово к реализации` (или согласно фактическому вердикту).

С прошлой проверки от `<дата из последнего reports/verification-*.md или «пропуск» если первый запуск после ручной правки>` в артефактах ничего не изменилось по снимку `snapshot` (или: проверены только отмеченные задачи — одна строка).

По плану — `<одна следующая команда или статус активного среза>`.

Подробности в прошлом отчёте: `openspec/changes/<name>/reports/verification-<...>.md` (если отчёт есть; если нет — указать первую проверку).

---

## Информативный вариант — когда есть находки, авто-поправки или разговорное обсуждение

```
ЗНИ: <имя-change> — <Готово к реализации | Готово с оговорками | Не готово>: <одна фраза>.

Что нашли:
- <одна строка на нестыковку «что случилось / почему важно»>
- <…>
(пропускайте блок, если новых находок нет.)

Сама поправила:
- <что сделано автоматически + кратко где>
- <…>
(пропускайте блок, если Phase A не сработала.)

Что обсудим:
<вставить один блок на развилку по шаблону card-decision.md — параграфы, без Na/Nc>

По плану (известные открытые вопросы, не блокирующие если в артефактах уже есть owner-задача):
- <одна строка: тема → закроется в S<N>.<M> или в задаче из tasks.md>
(пропускайте блок, если таких нет.)

Подробности: `openspec/changes/<name>/reports/verification-YYYY-MM-DD.md`
```

При открытых темах после «Что обсудим»: конец сообщения может быть формулировкой вроде «Напишите в ответ своими словами, какой вариант ближе, или свой вариант».

---

### Анти-пример

Требовать «ответьте `1a` или `2b`» или отправлять за развилкой только в файл — **запрещено**.
