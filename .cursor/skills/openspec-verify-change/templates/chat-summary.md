**ЗНИ:** `<имя-change>` (одна строка; без лишнего текста).

**Готовность: <Готово к реализации | Готово с оговорками | Не готово>** — <одна фраза, почему так>.

**Что не так** (по пунктам, без «воды»; каждый пункт — один проверяемый факт):
1. <факт 1, язык заказчика>
2. <факт 2>
3. <факт 3, если есть>

**Решения** — только если в файле отчёта есть блоки «Нужны решения» / «Уточнения текста артефактов» (каждая карточка или строка гигиены → один блок ниже). Если решений нет — секцию **полностью опустить**.

Для каждого решения сквозная нумерация `N = 1, 2, 3…`:

**Решение N — <короткое название проблемы>:**
- `<N>a` — <действие одной строкой> → <последствие для кода или приёмки>
- `<N>b` — <альтернатива одной строкой> → <последствие>
- `<N>c` — Принять как есть → <конкретный риск одной строкой>

(Decision, меняющее постановку или код: в строке варианта обязательно указать команду вида `/opsx:extend <имя-change> --from-verify <путь-к-отчёту>` — см. §8 `opsx-output-style.md`. Для гигиены текста допускается вариант «применить правку текста и повторить проверку».)

**От вас нужно** (нумерация обязательна, если пунктов больше одного):
1. Если блок **Решения** заполнен: «Выберите по каждому решению вариант `Na` / `Nb` / `Nc` и напишите в чат одну строку (например `1a, 2b, 3c`).»
2. Если секции **Решения** нет: «Решений не требуется» и одна строка следующего шага (например команда `/opsx:…`). (При отсутствии п.1 этот пункт становится единственным и нумеруется как 1.)
3. Дополнительные действия — при необходимости (не заменяют выбор по **Решениям**).

**Как ответить:** одна строка — например «Ответьте в чате: `1a` или `1b, 2a`», где номера **совпадают** с блоками **Решение N** выше. Если блоков **Решения** не было — формулировка под фактический пункт в **От вас нужно**.

**Подробности** (обоснования, риски, счётчики, полные тексты полей карточек из файла): `reports/verification-<mode>-YYYY-MM-DD.md`. Запрещено отправлять пользователя в файл **вместо** перечисления вариантов `Na`/`Nb`/`Nc` в чате.

**От вас нужно**
