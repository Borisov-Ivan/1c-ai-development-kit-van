# session-retro

Зафиксировать короткую ретроспективу сессии для автора kit / команды.

## Шаги

1. Создать `temp/session-retro-YYYY-MM-DD.md` (дата локальная):

```markdown
# Retro — <YYYY-MM-DD>

## Что сработало
- …

## Что улучшить
- …

## Идеи в backlog kit
- … (опционально; не создавать ЗНИ автоматически)
```

2. Не запускать apply/writer. Не править код.
3. В чат: путь к файлу + при желании «для новой ЗНИ: `/opsx:explore`».
