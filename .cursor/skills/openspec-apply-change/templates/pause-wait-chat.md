# pause-wait — карточка чата (SSOT)

Когда `/opsx:apply` останавливается, потому что **следующий шаг человека** — создать или поправить объекты в Конфигураторе, выгрузить расширение или завести доп.реквизиты в ИБ. Не развилка A/B.

Файл рецепта: [pause-wait-file.md](pause-wait-file.md). Бюджет: `chat-output-budget.mdc` §1d. Стиль: `opsx-output-style.md` §5.2.

## Слоты (все обязательны)

1. **Где мы** — первая строка, отдельным абзацем. Что агент **не** делает и почему (код пока не пишу: некуда класть / форму правите вы). Без slug change как единственной сути. Без «0/N задач».
2. **Что создать** — нумерованный список до **7** пунктов. Имя объекта 1С (при необходимости в backticks) + зачем одной фразой. Человек может начать Конфигуратор по этому списку.
3. **Ловушки** — 0–3 коротких предупреждения человеческим языком (где платформа не запишет строку, что не создавать «как в 3.0»).
4. **Детали** — одна строка: путь к `reports/handoff-pause-S<N>-YYYY-MM-DD.md` **и имя раздела** «Что создать в Конфигураторе». Не «чеклист в §6», не ссылка без списка слота 2.
5. **Как вернуться** — выгрузить и написать в чат или `/opsx:apply <name>`. Если в живой базе имена уже другие — напишите фактические (сноска, не варианты A/B).

## Запрещено

- Таблица «Следующие задачи» и прогресс `M/N`.
- Список отсутствующих XML / символов выгрузки как тело сообщения.
- Подмена слота 2 развилкой «сделать чеклист» vs «имена другие».
- Копирование абзаца из `tasks.md`.
- Ярлык «Пошаговая пауза», Schema, имена агентов.

## Эталон

```markdown
Код кнопок в дереве файлов пока не пишу: в расширении ещё нет объектов, куда его класть.

Сейчас вы в Конфигураторе (расширение «Павлик»). Нужно создать:

1. Два перечисления: где висит кнопка и что она делает
2. Три поля в справочнике кнопок и модуль объекта
3. Поля на форме элемента справочника
4. Общий модуль флажков файла и подписку «перед записью» файла
5. Три строки в макете доп. настроек
6. В базе — три доп.реквизита набора «Файлы» (не поля справочника, как в 3.0)

Два места, где легко сломать запись: у «Шаблона процесса» снимите автопроверку заполнения; флажки — доп.реквизиты набора файлов, не реквизиты метаданных.

Детали типов, имён значений и флажков модуля — в файле паузы, раздел «Что создать в Конфигураторе».
Когда выгрузите — напишите в чат или `/opsx:apply <name>`. Если в живой базе имена уже другие — напишите фактические.
```
