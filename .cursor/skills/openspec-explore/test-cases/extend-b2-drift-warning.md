# Test-case: extend B2 — drift-warning

Регрессия брифа с развилкой для `/opsx:extend` при расширении scope.

## Вход

```
/opsx:extend signing-contract-sign-verify-bytes добавить поддержку локального УНЭП наравне с облачным для исключения полей подписанта
```

Предусловие: в `design.md` Non-Goals или Why ограничивают scope облачным УНЭП → `Drift-check: drift-warning`.

## Контрольные точки

| # | Ожидание | FAIL если |
|---|----------|-----------|
| 1 | Бриф **B2** ≤8 строк | >8 строк или B3 с полным **План** исследования |
| 2 | Слот **Риск / развилка** с одной A/B прозой | Нет развилки при drift-warning |
| 3 | `Drift-check` только в internal → `debug.md` | `Drift-check:` в чате |
| 4 | Нет «Как буду искать» / плана артефактов | Нумерованный список proposal/design/tasks |

## Эталон B2

```markdown
Бриф: signing-contract-sign-verify-bytes

**От вас** — добавить поддержку локального УНЭП наравне с облачным для исключения полей подписанта.
**Цель** — расширить правило исключения полей: не только облачный УНЭП.
**Риск / развилка** — это меняет поведение для локальных сертификатов, ранее вне scope. **A.** Только облачный УНЭП (как в текущем Why). **B.** Оба типа УНЭП с отдельными условиями в требованиях.
**На выходе** — уточнённые требования и задачи по выбранному варианту.
**Подтвердить?** — «A» / «B» или уточните.
```
