## Почему плохо

1. Все точки и все оси сразу — нельзя обсуждать детали.
2. Нет «что берётся / как» по конкретной конструкции.
3. Нет фрагмента кода — заказчик не видит замер.
4. Решение про «всю систему» вместо одной логической развилки.
5. Похожие сущности (две РГ) свалены без «зачем эта / чем не та».

## Как надо

Сначала карта имён точек (≤12 строк). Затем **одна** карточка по `templates/point-card.md` — как в `voice-good-point.md`.
