**1/10. Шаблон процесса подписания**

**Зачем смотрим** — от найденного шаблона зависят и появление кнопки, и какой процесс стартует. Важно понять, откуда берётся ссылка — не про маршрут внутри шаблона.

**Что берётся** — ссылка на элемент справочника `ШаблоныИсполнения`.

**Как берётся** — по типу предмета вызывается `НайтиПоКоду` с зашитым кодом; только на ИБ Павлик. Пустая ссылка — кнопки не будет.

**Где в коде**

```613:624:src/ДО2/cf/CommonModules/pavУсловияМашрутизации/Ext/Module.bsl
Функция pavШаблонПроцессаПодписанияСсылка(Предмет) Экспорт
	pavШаблонПроцессаПодписанияСсылка = Справочники.ШаблоныИсполнения.ПустаяСсылка();
	Если pavОбщийМодуль.pavЭтоИБПавлик() Тогда
		Если ТипЗнч(Предмет) = Тип("СправочникСсылка.ВнутренниеДокументы") Или ТипЗнч(Предмет) = Тип("СправочникОбъект.ВнутренниеДокументы") Тогда
			pavШаблонПроцессаПодписанияСсылка = Справочники.ШаблоныИсполнения.НайтиПоКоду("00-00000000000000000000000000000000000000000007981"); //Это для Павлика
		ИначеЕсли ТипЗнч(Предмет) = Тип("СправочникСсылка.ИсходящиеДокументы") Или ТипЗнч(Предмет) = Тип("СправочникОбъект.ИсходящиеДокументы") Тогда
			pavШаблонПроцессаПодписанияСсылка = Справочники.ШаблоныИсполнения.НайтиПоКоду("00-00000000000000000000000000000000000000000039933"); //Это для Павлика
		КонецЕсли;
	КонецЕсли;
	
	Возврат pavШаблонПроцессаПодписанияСсылка
КонецФункции
```

**На что смотреть** — зашитые коды внутри `НайтиПоКоду(...)` (хвосты `07981` / `39933`), не имя функции.

**Почему важно** — сменить шаблон сейчас можно только правкой кода. Для новой ветки Согласования тот же вопрос: откуда брать ссылку на шаблон (кандидат в сводку анализа на выходе, без A/B здесь).
