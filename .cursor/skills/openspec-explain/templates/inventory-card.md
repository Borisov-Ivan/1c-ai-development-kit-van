# Карта точек (SSOT) — `/opsx:explain`

Показать **после** подтверждения entry-брифа, **до** первой карточки точки. Без кода, без вариантов A/B. Классы точек (`решение` / `наблюдение` / `типовое`) — **agent-only**, в чат не выводить.

## Форма в чат (≤12 строк)

```markdown
**Карта:** <тема эффекта одной фразой>

1. <имя эффекта>
2. …
N. <имя> (можно не разбирать)

Подтвердить список? — «да» / что убрать или добавить.
```

## Правила

- Порядок = порядок прохода (сценарий: открытие → клик → сервер → старт → UX).
- Имя точки — язык эффекта для пользователя («шаблон по коду», не `pavШаблон…` в заголовке карты; идентификатор — на карточке точки).
- Типовой механизм ДО/платформы: в карте одна пометка `(можно не разбирать)` — без слова «класс» и без абзаца про «полную карточку».
- Не включать сюда таблицу hardcode/настройки целиком — только имена точек.
- Не просить «сменить класс» — пользователь правит список (убрать / добавить); класс агент пересчитывает внутри.
