# Карта точек (SSOT) — `/opsx:explain`

Показать **после** подтверждения entry-брифа, **до** первой карточки точки. Без кода, без вариантов A/B.

## Форма в чат (≤12 строк)

```markdown
**Карта разбора:** <тема одной фразой>

1. <имя точки> — решение | наблюдение | типовое (пропуск)
2. …
N. …

Типовые по умолчанию не разбираем полной карточкой (кроме явной просьбы или если критичны для соседних решений).

Подтвердить охват? — «да» / что убрать или добавить / сменить класс пункта.
```

## Правила

- Порядок = порядок прохода (сценарий: открытие → клик → сервер → старт → UX).
- Имя точки — язык эффекта или сущности («шаблон по коду», не `pavШаблон…` в заголовке карты; идентификатор — на карточке точки).
- Класс **типовое**: в карте одна пометка «пропуск»; не раздувать список пояснениями.
- Не включать сюда таблицу hardcode/настройки целиком — только имена точек.
