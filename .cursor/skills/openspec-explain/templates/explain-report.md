## Citation (файл)

На каждый фрагмент кода в журнале — **два слоя**:

1. **Nav-link (hybrid)** — кликабельный переход к модулю:

```markdown
[`613:624:src/Конфигурация/cf/CommonModules/extУсловияМаршрутизации/Ext/Module.bsl`](../../src/Конфигурация/cf/CommonModules/extУсловияМаршрутизации/Ext/Module.bsl)
```

| Расположение отчёта | Относительный href к `src/...` |
|---------------------|--------------------------------|
| `temp/reports/` | `../../src/...` |
| `openspec/changes/<name>/reports/` | `../../../../src/...` |

- В **label** ссылки — канон от корня репо: `start:end:src/...` (как в чате).
- В **href** — путь относительно файла отчёта (таблица выше).
- **При переезде** журнала из `temp/reports/` в `openspec/changes/<name>/reports/`: поправить относительный href `../../src/` → `../../../../src/` (канон таблицы). Label citation `start:end:src/...` не менять. Секцию `## Вводные` из‑за переезда не добавлять.

2. **Fence с телом** — тот же диапазон и путь в info-string, что ушёл в карточку чата (для чтения без прыжка):

````markdown
```613:624:src/Конфигурация/cf/CommonModules/extУсловияМаршрутизации/Ext/Module.bsl
<тело фрагмента>
```
````

В чате — только fence (без обязательного nav-link). В файле — nav-link **и** fence.

## Правила сборки

1. Писать на **выходе** (§4): после шага A обязательно; после шага B — перезаписать с «Заметки»; при фиксации постановки — дописать `## Постановка ЗНИ` в тот же файл.
2. Журнал содержит **все пройденные** точки (не только кандидаты). Пропущенные `(можно не разбирать)` — в карте с пометкой; полных карточек для них нет, если не разбирали.
3. **Класс (agent)** в файле обязателен для каждой карточки журнала; в чат классов не выносить.
4. Текст слотов карточки = тот же смысл, что в чате (можно чуть полнее, без жаргона HALT голоса skill).
5. Не дублировать целиком отчёты explore/trace — только ссылки в **Мета → Источники**.
6. HALT голоса skill (`гейт`, `литерал`, `as-is`, …) действует и в файле.
7. Отдельную `## Вводные` **не** требовать, если «Мета» заполнена сценарием и вопросом. Если объекта нет — одна строка «Объекты / пути из постановки» в «Мета», не вторая шапка. Правило href при переезде — в секции Citation, здесь не дублировать.
