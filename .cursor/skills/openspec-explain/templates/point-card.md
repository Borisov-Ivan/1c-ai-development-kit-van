# Карточка точки (SSOT) — `/opsx:explain`

Один ход = одна точка. Бюджет чата: **15–35 строк**. Эталон голоса: `fixtures/voice-good-point.md`. Класс точки — **agent-only** (выбор хвоста); в заголовок чата не писать.

## Форма

```markdown
**N/M. <имя эффекта>**

**Зачем смотрим** — <1–2 предложения: роль в сценарии. Если похоже на другую точку — чем отличается, назвав соседнюю по делу.>

**Что берётся** — <какие данные/ссылки/признаки.>

**Как берётся** — <зашитая строка или код / запрос / API / реквизит формы / настройка — одним-двумя предложениями.>

**Где в коде**

<один цитатный блок 8–25 строк в формате start:end:path>

**На что смотреть** — <какая строка / зашитое значение / ветка несёт смысл; без метафор, которые нельзя найти в фрагменте.>

**Почему важно** — <что будет при ошибке здесь; или почему обычно оставляют как есть.>

<хвост по agent-классу>
```

## Хвост по классу (класс не в заголовке)

### решение

```markdown
**Что решить**

- **A.** …
- **B.** …
- **C.** …   <!-- опционально -->

**Следующий шаг:** A, B или C (или уточните).
```

### наблюдение

```markdown
**Дальше:** «понял» / «дальше» — следующая точка; или уточните, если нужно углубить.
```

### типовое (только если показали полную карточку)

```markdown
Типовой механизм — вариантов постановки нет. **Дальше:** «понял» / «дальше».
```

## Правила сборки

1. **Зачем смотрим** обязателен; при двух похожих проверках / рабочих группах — явно «это не то же самое, что …» с именем соседней точки по делу.
2. Без фрагмента и без «Что/Как» карточку не отправлять.
3. **На что смотреть** не дублирует весь код: одна фраза, привязанная к видимой конструкции; слова «литерал», «гейт», `as-is` — запрещены (см. HALT голоса в SKILL).
4. Если речь об отказе/предупреждении пользователю — процитировать или пересказать **текст**, который видит пользователь.
5. Второй цитатный блок — только вызов↔определение.
6. Не добавлять таблицы «всех настроек» и не пересказывать следующие точки.
7. После ответа на **решение** — в следующем сообщении первой строкой: `**Зафиксировано:** …`.
