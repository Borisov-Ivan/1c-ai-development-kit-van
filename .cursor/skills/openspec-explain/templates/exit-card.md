# Выход прохода (SSOT) — `/opsx:explain`

После последней точки карты, «хватит» или «собери итог». Эталон голоса: `../fixtures/voice-good-exit.md`.  
Журнал файла: [`explain-report.md`](explain-report.md).

---

## Артефакт журнала (обязательно)

На выходе (после шага A; при шаге B — перезаписать с «Заметки») — **`Write`** файла по [`explain-report.md`](explain-report.md):

| Контекст | Путь |
|----------|------|
| Нет привязки к ЗНИ | `temp/reports/explain-YYYY-MM-DD-<slug>.md` |
| Change в брифе/контексте | `openspec/changes/<name>/reports/explain-YYYY-MM-DD-<slug>.md` |

В **каждом** финальном сообщении выхода в чат — строка:

```markdown
Журнал: `<путь-к-explain-*.md>`
```

Без дампа содержимого файла. Отдельный `temp/explain-handoff-*.md` **не создавать**.

---

## Шаг A — журнал + вопрос (END TURN)

Бюджет: **≤6 строк** списка пройденного + вопрос (плюс строка «Журнал: …»; путь не считается в лимит списка).

### Если есть кандидаты анализа

Кандидат = agent-класс **решение** на пройденной точке **или** явная хрупкость, отмеченная в **Почему важно** (зашито / особый случай / риск для новой ветки).

```markdown
**Пройдено**
1. <имя эффекта>
2. …
N. …

Нужен доп. анализ проблем и рисков по рассмотренным пунктам? — «да» / «нет».

Журнал: `temp/reports/explain-YYYY-MM-DD-<slug>.md`
```

### Если кандидатов нет

```markdown
**Пройдено**
1. …
N. …

Журнал: `temp/reports/explain-YYYY-MM-DD-<slug>.md`

**Следующий шаг:** достаточно / вернуться в `/opsx:explore` / уточните.
```

Вопрос про анализ **не** навязывать, если кандидатов нет (кроме явного «собери итог» / «какие риски» от пользователя).

На шаге A файл уже записан (карта + журнал точек; секция «Заметки» — пустая или отсутствует).

---

## Шаг B — сводка заметок (после «да»)

Не повтор всех карточек и не чеклист «багов». Только кандидаты. В чат **≤5 пунктов**; если больше — «и ещё N — скажите, какой углубить». Бюджет: **≤25 строк** (+ строка «Журнал: …»).

Тон: «заметка / риск», не «баг», если это осознанный hardcode. HALT голоса skill — без исключений.

```markdown
**Заметки по пройденному**

1. **<имя эффекта>** — <одна фраза: что хрупко / зашито и чем это бьёт>.
   Можно: <вариант 1>; <вариант 2>; <оставить как есть>.
2. …

Журнал: `temp/reports/explain-YYYY-MM-DD-<slug>.md`

**Следующий шаг:** зафиксировать в постановке (`/opsx:new` / `/opsx:extend`) / достаточно / уточните пункт.
```

Перезаписать тот же `explain-*.md` с секцией **Заметки**.

При выборе зафиксировать — блок `## Постановка ЗНИ` по [`openspec-explore/templates/handoff-block.md`](../../openspec-explore/templates/handoff-block.md) **дописать в тот же** `explain-*.md` (и при необходимости показать в чате).

---

## После «нет» на шаге A

Одно из:

- «достаточно»;
- вернуться в `/opsx:explore` (если explain был из середины исследования);
- уточнение пользователя текстом.

Строка «Журнал: …» обязательна (файл уже записан на шаге A).
