# Выход прохода (SSOT) — `/opsx:explain`

После последней точки карты, «хватит» или «собери итог». Эталон голоса: `fixtures/voice-good-exit.md`.

---

## Шаг A — журнал + вопрос (END TURN)

Бюджет: **≤6 строк** (журнал может быть короче списка карты — 1 строка на пройденный эффект).

### Если есть кандидаты анализа

Кандидат = agent-класс **решение** на пройденной точке **или** явная хрупкость, отмеченная в **Почему важно** (зашито / особый случай / риск для новой ветки).

```markdown
**Пройдено**
1. <имя эффекта>
2. …
N. …

Нужен доп. анализ проблем и рисков по рассмотренным пунктам? — «да» / «нет».
```

### Если кандидатов нет

```markdown
**Пройдено**
1. …
N. …

**Следующий шаг:** достаточно / вернуться в `/opsx:explore` / уточните.
```

Вопрос про анализ **не** навязывать, если кандидатов нет (кроме явного «собери итог» / «какие риски» от пользователя).

---

## Шаг B — сводка заметок (после «да»)

Не повтор всех карточек и не чеклист «багов». Только кандидаты. В чат **≤5 пунктов**; если больше — «и ещё N — скажите, какой углубить». Бюджет: **≤25 строк**.

Тон: «заметка / риск», не «баг», если это осознанный hardcode. HALT голоса skill — без исключений.

```markdown
**Заметки по пройденному**

1. **<имя эффекта>** — <одна фраза: что хрупко / зашито и чем это бьёт>.
   Можно: <вариант 1>; <вариант 2>; <оставить как есть>.
2. …

**Следующий шаг:** зафиксировать в постановке (`/opsx:new` / `/opsx:extend`) / достаточно / уточните пункт.
```

При выборе зафиксировать — при необходимости блок `## Постановка ЗНИ` по [`openspec-explore/templates/handoff-block.md`](../../openspec-explore/templates/handoff-block.md).

---

## После «нет» на шаге A

Одно из:

- «достаточно»;
- вернуться в `/opsx:explore` (если explain был из середины исследования);
- уточнение пользователя текстом.

Handoff-файл — только по словесной просьбе → `temp/explain-handoff-YYYY-MM-DD-<slug>.md`.
