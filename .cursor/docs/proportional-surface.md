# Пропорциональная поверхность BSL (on-demand)

Инвариант: **поверхность реализации пропорциональна** доставленному поведению и ясности для читателя.

## Что ловим

- Церемония без вклада (пустые обёртки, дублирующие слои, «шум» имён/комментариев).
- Низкая читаемость из‑за шума, а не из‑за intrinsic complexity домена.

## Что не делаем

- Не раздуваем каталог AP новым длинным списком — принцип + REFACTOR.
- Q1 Phase 0 (`DISPROPORTIONATE_COMPLEXITY`) = сложность **домена**; поверхность = отдельный сигнал (`DISPROPORTIONATE_SURFACE`).

## Стык

- Reviewer: ≥1 REFACTOR при систематическом шуме поверхности.
- Apply/review: обязанность не закрывать задачу — якорь поверхности в `.cursor/rules/1c-agent-delegation.mdc`. Здесь второй формулы нет.
- Sidecar (S5) **не** несёт этот MUST.
