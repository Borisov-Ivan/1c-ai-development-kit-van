По файлу частного задания или по имени уже существующей задачи сначала записать лист вопросов и согласование часов. Для файла задания — рядом с ним, четыре файла считая техпроект и постановку после пометки. Для существующей задачи — три файла в корне её каталога, без постановки. Файлы техпроекта — только когда в листе уже есть непустая пометка подтверждения и команду запускают снова.

**Первое действие:** прочитать `.cursor/skills/openspec-techproject/SKILL.md` и идти по нему. До прочтения навыка не читать задание, шаблоны и выгрузку.

**Input:**
- путь к файлу частного задания, либо имя уже существующей задачи, либо путь к её каталогу или к файлу в нём.

Папка `template/Техпроект` этой командой не читается. Файлы `.cursor/skills/openspec-overview/**` не менять.
